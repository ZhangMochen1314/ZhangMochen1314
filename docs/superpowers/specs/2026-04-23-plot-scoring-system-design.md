# 科研绘图模板自动生成与评分系统设计 (2023-04-23)

## 1. 目标与范围 (Goals & Scope)
当前项目已经有一系列的高级科研绘图 Python 脚本，涵盖了分布、回归、时间序列、网络模型等领域。现在的目标是：
- 重新配置统一的全局风格：**所有**图片均导出为高清 PNG 格式，不含图片内部标题，尺寸遵循 A4 宽度 (6.3 英寸) 和黄金比例高度 (3.89 英寸)，字体配置符合提供的文档要求 (Times New Roman / SimSun, 9pt 等)。
- 将每个生成的结果隔离化：为每一种生成的图片类型创建一个专门的文件夹（以 `类型名_时间戳` 命名）。
- 为图片建立一个 **Web 交互式评分系统**：用户可以通过滑动条 (0-100分) 为每一种图表的学术风和商业风打分，最终选出最佳模板。

## 2. 目录与文件输出结构 (Output Structure)
每次运行 `generate_all.py` 时，将在特定的根输出目录（如 `output_templates/`）下创建如下层级：
```
output_templates/
  └── violin_plot_1682312345/
      ├── academic.png         # 学术版高清图片
      ├── commercial.png       # 商业版高清图片
      ├── source_code.py       # 用于生成该图表的 Python 源码备份
      └── info.md              # 该图表类型的说明文档
```

## 3. 核心模块与实现思路 (Implementation Approach)

### 3.1 风格配置 (style_manager.py 修改)
- **字体与尺寸**：统一设置 `figure.figsize: (6.3, 3.89)`。字体确保为 `['Times New Roman', 'SimSun', 'sans-serif']` 和 9pt 字号。
- **取消标题**：添加配置强制去除图内标题。
- **统一输出**：无论是 `academic` 还是 `commercial` 风格，均输出为 `dpi=300`（或更高）的 `.png`。

### 3.2 生成脚本修改 (generate_all.py)
- 创建 `output_templates` 目录。
- 在循环调用各个 `plot_*.py` 中的函数时，不再直接把图片扔到根目录。
- 使用 `os.makedirs` 创建 `图表名_时间戳` 的文件夹。
- 把生成的 PNG 文件保存至该文件夹。
- 自动写入一个 `info.md` 到该文件夹内。
- 复制调用的绘图源码到 `source_code.py`。

### 3.3 评分应用 (score_app.py)
- 基于 `Gradio` (或类似的快速 Web UI 框架) 搭建一个本地服务。
- 启动时扫描 `output_templates` 目录。
- 在界面中展示下拉菜单或翻页功能，切换不同的图表任务。
- 界面并排显示 `academic.png` 和 `commercial.png`。
- 提供两个 `0-100` 的滑块 (`Slider`)，分别用于对学术风格和商业风格进行打分。
- 提供一个“保存评分”按钮，将当前的图表打分结果写入到一个全局的 `scores.csv` 文件中，方便后续筛选“完美模板”。

## 4. 边界条件与错误处理 (Error Handling)
- **字体缺失警告**：如果在沙盒/无头环境中执行，可能会报字体找不到的警告。这不影响生成和打分流程。
- **Gradio 启动**：确保应用绑定到 `0.0.0.0`，允许在沙盒外访问或通过分配的 URL 进行交互评分。
