# DeepTrace-Literature 文献综述

## 项目简介
DeepTrace-Literature 是 DeepTrace 系列的文献综述模块，用于智能搜集社科顶刊文献并生成综述报告。

## 任务目标
- 本 Skill 用于：智能搜集或解析学术文献，生成学术文献综述报告和可视化HTML报告
- 能力包含：网络文献搜集、文献文件解析、研究要素提取、主题聚类归纳、综述撰写、HTML报告渲染
- 触发条件：用户提出研究主题需搜集文献，或用户上传文献文件需生成报告

## 输出格式

本Skill默认输出两种格式文件：

| 输出文件 | 格式 | 说明 |
|---------|------|------|
| `文献综述报告.md` | Markdown | 学术文献综述报告 |
| `文献报告.html` | HTML | 可视化HTML报告 |

**输出一致性原则（强制）**：
- MD报告和HTML报告的**参考文献列表必须完全一致**
- 两份报告使用**同一批文献数据**生成
- 文献编号、引用顺序、参考文献格式保持一致

### 格式一：学术文献综述报告（Markdown）
- **格式要求**：学术论文格式，包含引言、主体、结论、参考文献
- **引用格式**：采用数字标注格式[1][2][3]，按出现顺序编号
- **参考文献**：按APA格式列出完整参考文献列表

### 格式二：可视化HTML报告
- **格式要求**：网页格式，包含检索概览、论文列表、详细综述内容、参考文献列表
- **报告标题**：固定为"DeepTrace社科顶刊论文研究报告"
- **用途**：便于快速浏览文献信息

## 操作流程

### 方式一：用户提出研究主题 → 智能体网络搜集

#### 步骤1：理解研究需求
分析用户提出的研究主题或问题，明确：
- 研究领域和核心关键词

**文献数量要求（强制执行）**：
- **默认数量**：必须搜集**30篇**文献
- **用户指定**：用户指定数量时，必须严格按用户要求执行
- **不可随意减少**：除非数据库确实无更多结果，否则必须达到目标数量

**期刊等级要求**：
- **优先核心期刊**：中英文核心期刊（中文：CSSCI、北大核心；英文：SCI/SSCI等）
- **补充策略**：若核心期刊数量不足，使用普通期刊补充
- **用户指定优先**：用户指定期刊类型时，严格按用户要求执行

| 参数 | 默认值 | 用户可指定 | 执行要求 |
|------|--------|-----------|---------|
| 文献数量 | **30篇（必须）** | 任意数量 | 严格按此数量执行 |
| 期刊等级 | 核心期刊优先，不足时用普刊补充 | 仅核心/仅普刊/指定期刊名称 | 严格按用户要求执行 |
| 时间范围 | 近10年 | 任意时间范围 | 严格按用户要求执行 |

#### 步骤2：网络搜索文献信息
通过网络搜索获取文献的**基本信息**（无需深入获取完整论文内容）：

**搜索方式**：
- 使用搜索引擎搜索"研究主题 + 论文"、"研究主题 + 期刊"等关键词
- 搜索知网、万方、Web of Science等数据库的公开页面
- 搜索学术期刊官网的相关论文页面

**需要获取的信息**：
- ✅ **论文标题**（中英文）
- ✅ **作者姓名**（用分号分隔）
- ✅ **期刊名称**
- ✅ **出版年份**
- ✅ **摘要内容**（重要！用于撰写综述）
- ✅ **关键词**（如有）
- ✅ **DOI或文章链接**（如有）

**注意**：
- 只需获取公开可访问的基本信息，无需付费下载全文
- 摘要内容通常在搜索结果或期刊预览页面即可获取
- 如果某些信息无法获取，用"未知"或空字符串填充

#### 步骤3：整理文献信息
整理每篇文献的基本信息（无需获取全文）：
- 标题（中英文）
- 作者（用分号分隔）
- 期刊名称
- 出版年份
- 摘要（中英文）- **核心信息，用于撰写综述**
- 关键词
- DOI或文章链接（如有）

**信息来源**：
- 搜索引擎结果摘要
- 知网/万方等数据库的论文预览页
- 期刊官网的论文介绍页
- Google Scholar的搜索结果

---

### 方式二：用户上传文献文件 → 智能体解析

**核心原则**：仅基于用户上传的文献内容撰写综述，**禁止捏造或虚构任何文献信息**。

#### 步骤1：识别文件格式
用户上传的文献文件格式：
- **BibTeX (.bib)** - 直接读取解析
- **RIS (.ris)** - 直接读取解析
- **EndNote XML** - 直接读取解析
- **Excel/CSV** - 直接读取表格内容
- **PDF文件** - 读取PDF文本内容
- **Word文档** - 读取文档内容

#### 步骤2：智能体解析文件
直接读取文件内容，提取文献信息：
- BibTeX/RIS/XML：解析结构化字段
- Excel/CSV：读取表格列数据
- PDF：提取文本，识别标题、作者、摘要等
- Word：读取文档内容

#### 步骤3：基于上传文献撰写综述
- **仅使用用户上传的文献**：综述内容必须完全基于上传文件中的实际内容
- **禁止捏造**：不得虚构、添加或扩展任何文献信息
- **如实反映**：如果文献信息不完整（如缺少摘要），按实际内容处理，不补充
- **引用准确**：参考文献列表仅列出上传文件中实际存在的文献

#### 步骤4：生成报告
**输出格式与网络搜集方式完全一致**：
- 输出文件：`文献综述报告.md` + `文献报告.html`
- HTML报告结构：检索概览 → 论文列表 → 综述内容 → 参考文献
- 使用相同的HTML模板和占位符填充规则
- 表格、弹窗、参考文献格式保持一致

#### 步骤5：用户要求补充搜集（可选）
如果用户明确要求"在此基础上搜集更多文献"或类似表述：
- 使用网络搜索补充文献
- 将补充文献与用户上传文献合并后重新生成综述
- 在报告中区分标注"用户上传文献"和"网络搜集文献"

## 报告生成

### 一、学术文献综述报告（Markdown格式）

#### 1. 综述结构

按学术论文格式组织：

```markdown
# [研究主题]文献综述报告

## 摘要
[简要概述研究背景、主要发现和研究意义，200-300字]

## 一、引言
### 1.1 研究背景
### 1.2 研究目的与意义
### 1.3 文献检索范围

## 二、文献综述
### 2.1 [研究主题一]
[综述该主题下的主要研究，引用相关文献，使用数字标注格式[1][2]]

### 2.2 [研究主题二]
[综述该主题下的主要研究，引用相关文献，使用数字标注格式[3][4]]

### 2.3 [研究主题三]
[综述该主题下的主要研究，引用相关文献，使用数字标注格式[5][6]]

## 三、研究方法综述
### 3.1 主要研究方法
### 3.2 方法论发展趋势

## 四、研究不足与展望
### 4.1 现有研究的不足
### 4.2 未来研究方向

## 五、结论

## 参考文献
[按APA格式列出所有参考文献，按正文引用顺序编号]
```

#### 2. 引用格式要求

**正文引用格式**（数字标注，按出现顺序编号）：
- 单篇文献：[1]
- 多篇文献：[1][2][3]
- 引用必须按正文出现顺序编号

**示例**：
```
数字经济成为推动经济高质量发展的重要引擎[1]。现有研究表明，
数字经济对生产力提升具有显著正向影响[2][3]。张三等[4]进一步指出...
```

**参考文献列表格式**（APA格式，按正文引用顺序编号）：
```
[1] 作者. (年份). 文章标题. 期刊名称, 卷号(期号), 页码.
[2] 张三, 李四, 王五. (2024). 数字经济对新质生产力的影响研究. 管理世界, 40(3), 45-67.
[3] Wang, L., Chen, M., & Zhang, W. (2024). Digital economy and productivity. Journal of Management, 50(2), 123-145.
```

#### 3. 综述撰写要点

- **论点+文献支撑**：每个论点必须引用相关文献
- **批判性评述**：分析不同文献的观点差异和争议
- **逻辑连贯**：使用过渡句连接各部分
- **避免简单罗列**：进行综合分析和归纳

### 二、可视化HTML报告

#### 1. HTML模板结构

基于 `assets/report_template.html` 模板生成，包含以下部分：

**固定结构**：
- **报告标题**：固定为"DeepTrace社科顶刊论文研究报告"
- **一、检索结果概览**：检索来源、检索要求、结果概览（论文篇数、研究主题归纳、研究方法归纳、研究总结）
- **二、研究主题分析**：详细综述内容
- **三、研究方法分析**：研究方法综述
- **四、研究展望**：未来研究方向
- **五、参考文献**：按APA格式列出

#### 2. 占位符填充

**替换占位符**：
- `{{FILTER_INFO}}` → 期刊等级信息
- `{{QUERY}}` → 用户研究主题
- `{{YEAR_SUMMARY}}` → 论文篇数统计
- `{{TOPICS}}` → 研究主题列表（使用`<ol>`标签）
- `{{METHODS}}` → 研究方法列表（使用`<ol>`标签）
- `{{SUMMARIES}}` → 研究总结列表（使用`<ol>`标签）
- `{{TABLE_ROWS}}` → 论文列表表格行HTML
- `{{REVIEW_CONTENT}}` → 综述内容HTML（第二~四部分）
- `{{REFERENCES}}` → 参考文献列表HTML
- `{{MODALS}}` → 论文详情弹窗HTML

**列表格式要求**（使用有序列表显示序号）：
```html
<ol class="summary-list">
    <li>研究主题一</li>
    <li>研究主题二</li>
    <li>研究主题三</li>
</ol>
```

**综述内容格式**：
```html
<section>
    <h2>二、研究主题分析</h2>
    <div class="review-block">
        <h3>2.1 [主题一]</h3>
        <p>综述内容，引用文献使用数字标注[1][2]...</p>
    </div>
    <div class="review-block">
        <h3>2.2 [主题二]</h3>
        <p>综述内容，引用文献使用数字标注[3][4]...</p>
    </div>
</section>

<section>
    <h2>三、研究方法分析</h2>
    <div class="review-block">
        <p>研究方法综述内容...</p>
    </div>
</section>

<section>
    <h2>四、研究展望</h2>
    <div class="review-block">
        <p>未来研究方向...</p>
    </div>
</section>
```

**参考文献格式**：
```html
<div class="reference-item">
    [1] 作者. (年份). 文章标题. 期刊名称, 卷号(期号), 页码.
</div>
<div class="reference-item">
    [2] 张三, 李四. (2024). 论文标题. 管理世界, 40(3), 45-67.
</div>
```

**表格行格式**：
```html
<tr>
    <td data-label="序号">1</td>
    <td data-label="标题">
        <a href="javascript:void(0)" class="table-title-link" onclick="openModal('list-1')">
            中文标题
        </a>
    </td>
    <td data-label="期刊">期刊名称</td>
    <td data-label="时间">2024-01</td>
    <td data-label="操作">
        <a href="文章链接URL" target="_blank">查看原文</a>
    </td>
</tr>
```

**弹窗（Modal）格式**（每篇论文一个弹窗，用于显示详细信息）：
```html
<div id="list-1" class="modal">
    <div class="modal-content">
        <span class="close" onclick="closeModal('list-1')">&times;</span>
        <h3 class="modal-title">
            中文标题
            <a href="文章链接URL" target="_blank" class="title-link">[查看原文]</a>
        </h3>
        <p><strong>英文标题：</strong>English Title</p>
        <p><strong>作者：</strong>作者1; 作者2; 作者3</p>
        <p><strong>期刊：</strong>期刊名称</p>
        <p><strong>出版时间：</strong>2024-01</p>
        <p><strong>关键词：</strong>关键词1; 关键词2; 关键词3</p>
        <h4>摘要</h4>
        <p>中文摘要内容...</p>
        <p><strong>英文摘要：</strong>English Abstract...</p>
    </div>
</div>
```

**弹窗编号规则**：
- 弹窗ID格式：`list-{序号}`，如 `list-1`、`list-2`、`list-3`...
- 每篇论文对应一个独立的弹窗
- 弹窗ID必须与表格行中的 `onclick="openModal('list-{序号}')` 一致

## 注意事项

- **文献数量**：建议15-30篇，确保综述充分
- **来源可信**：优先选择权威期刊、高被引论文
- **引用规范**：使用数字标注格式[1][2]，按出现顺序编号
- **批判思维**：避免简单罗列文献，应进行分析和评述
- **时间范围**：优先近10年文献，经典文献可不受此限
- **报告标题**：HTML报告标题固定为"DeepTrace社科顶刊论文研究报告"

**禁止捏造原则**（重要）：
- 用户上传文献时，仅基于上传内容撰写综述，**禁止虚构任何文献信息**
- 综述中的每一条引用都必须对应实际存在的文献
- 如文献信息不完整，按实际内容处理，不补充或编造
- 仅在用户明确要求时才进行网络搜索补充文献

### 示例1：用户提出研究主题
**用户**："我想研究数字经济对新质生产力的影响"

**智能体执行**：
1. 分析研究主题，提取关键词
2. 网络搜索相关学术文献（30篇）
3. 提取研究主题、方法
4. 撰写学术文献综述报告（Markdown，数字引用格式）
5. 生成可视化HTML报告（标题：DeepTrace社科顶刊论文研究报告）

**输出**：
- `文献综述报告.md` - 学术综述报告
- `文献报告.html` - 可视化报告
