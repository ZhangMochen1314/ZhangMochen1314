# DeepResValue 落地页更新计划

## 1. 摘要 (Summary)
将 `/workspace/DeepResValue落地页文案.md` 中的丰富文案（包括 Vibe Coding 概念、竞赛案例、工具替代、邀请机制等）深度整合到现有的前端落地页 `frontend/src/pages/Home.tsx` 中，同时保留当前高端的学术风视觉设计（如毛玻璃效果、蓝紫渐变、动画效果以及与后端交互的动态定价模块）。

## 2. 现状分析 (Current State Analysis)
- **当前状态**：`Home.tsx` 已经拥有一个基础的 Hero 首屏、产品展示图、六宫格特性介绍（"严谨、高效的学术引擎"）、动态定价模块以及简单的页脚。
- **文案要求**：MD 文档新增了大量的“对比”场景（如 Stata 代码 vs 自然语言）、具体的使用场景表述、竞赛直达车成功案例、5 步工作流的具体聊天示例、以及基于积分与校园大使的推广机制。
- **融合策略**：不能简单地用 Markdown 渲染组件，而需要将 MD 的文案拆解，转化为现代 SaaS 落地页的 UI 组件（如对比卡片、聊天气泡、时间线、网格布局等），嵌入到现有的页面结构中。

## 3. 拟定变更 (Proposed Changes)

将按照 MD 文档的十大模块，自上而下对 `Home.tsx` 进行重构与扩充：

### 3.1. 第一屏 (Hero Section) 重构
- **主标题与副标题**：更新为“重塑您的科研工作流”结合“用自然语言做数据分析，告别代码，开口就能出结果”。
- **核心标签**：更新上方的小标签为“🔥 Vibe Coding 新范式 | 🏆 国奖直达车 | 🎓 全流程覆盖”。
- **震撼对比表**：在原产品大图上方或下方，增加一个精巧的深色毛玻璃对比卡片（“传统方式” vs “DeepResValue方式”，突出“学Stata 2个月 vs 说出需求 10秒”的极速体验）。

### 3.2. 新增：Vibe Coding 新范式模块 (Section 2)
- **理念阐述**：“为什么非得学代码？”配合左文右码（或左右对比）的布局。
- **代码对比组件**：左侧展示传统的 Stata 晦涩代码块，右侧展示类似聊天气泡的自然语言对话界面（“帮我分析数字化转型...”），直观冲击用户视觉。

### 3.3. 新增：被替代的工具墙 (Section 3)
- **工具墙展示**：用网格展示被划掉的传统软件（Stata, SPSS, Python 等），配以红色的 ❌ 或删除线。
- **能力映射**：通过列表展示 DRV 底层是如何覆盖这些软件的（回归、数据处理、时间序列等），并给出具体的自然语言交互场景对照表。

### 3.4. 新增：国家级竞赛专区 (Section 4)

### 3.5. 新增：全流程能力与交互示例 (Section 5)
