# DeerFlow Sandbox Cleanup Script

This directory contains `cleanup_sandbox.py`, a script used to automatically clean up old temporary files and directories generated by the DeerFlow agent sandboxes. 

## What it does

By default, DeerFlow stores sandbox workspace files, uploaded data, and agent outputs in the `threads/` directory (located under your `DEER_FLOW_HOME` or `.deer-flow/`). Over time, these files can consume a significant amount of disk space.

The `cleanup_sandbox.py` script scans all thread directories and deletes any that haven't been modified in the last `N` days.

## Usage

You can run the script manually:

```bash
# Delete items not modified in the last 7 days (default)
python3 cleanup_sandbox.py

# Delete items not modified in the last 30 days
python3 cleanup_sandbox.py --days 30
```

## Cron Job Setup Guide

To automate this process on a cloud server, it is recommended to set up a Cron job.

1. Ensure the script is executable:
   ```bash
   chmod +x /path/to/deer-flow/backend/scripts/cleanup_sandbox.py
   ```

2. Open the crontab editor for the user running the backend:
   ```bash
   crontab -e
   ```

3. Add the following entry to run the cleanup script daily at 3:00 AM. (Replace `/usr/bin/python3` with your Python path if using a virtual environment, and update the script path accordingly):
   ```cron
   # Run sandbox cleanup daily at 3:00 AM, deleting files older than 7 days
   0 3 * * * /usr/bin/python3 /absolute/path/to/deer-flow/backend/scripts/cleanup_sandbox.py --days 7 >> /var/log/deerflow_cleanup.log 2>&1
   ```

4. Save and exit. The cron daemon will automatically install the new crontab.
