## AI工具使用原则

### 基本原则
1. **辅助而非替代**：AI工具作为辅助工具，不能替代独立思考和原创性工作
2. **透明公开**：使用AI工具的情况必须在"AI工具使用情况表"中如实填写
3. **学术诚信**：不得利用AI工具进行学术不端行为
4. **质量把控**：对AI生成的内容必须进行认真审核和修改，确保准确性

### 使用范围
AI工具可以在以下环节合理使用：
- 文献检索和整理
- 数据处理和分析的辅助
- 代码编写和调试
- 语言润色和格式调整
- 初稿提纲的构思

AI工具不能在以下环节使用：
- 核心观点和假设的提出
- 关键分析和结论的形成
- 创新性观点的生成
- 最终成果的直接生成

## 允许使用的场景

### 1. 文献检索和整理
**允许操作**：
- 使用AI工具辅助检索相关文献
- 使用AI工具整理文献摘要和要点
- 使用AI工具进行文献分类和归纳

**注意事项**：
- 必须亲自阅读核心文献
- 对AI整理的内容需核对准确性
- 引用格式需手动调整规范

### 2. 数据处理和分析
**允许操作**：
- 使用AI工具编写数据处理代码
- 使用AI工具辅助调试代码错误
- 使用AI工具解释统计结果

**注意事项**：
- 需理解代码含义和逻辑
- 需验证结果的正确性
- 不能让AI直接生成分析结论

### 3. 代码编写
**允许操作**：
- 使用AI工具生成基础代码框架
- 使用AI工具优化代码效率
- 使用AI工具调试代码错误

**注意事项**：
- 必须理解代码逻辑
- 需人工审核代码质量
- 不能直接使用AI生成的代码而不加修改

### 4. 语言润色
**允许操作**：
- 使用AI工具检查语法和拼写错误
- 使用AI工具优化语言表达
- 使用AI工具调整语句结构

**注意事项**：
- 不能改变原文核心观点
- 不能改变原文逻辑结构
- 需人工审核润色效果

### 5. 格式调整
**允许操作**：
- 使用AI工具调整参考文献格式
- 使用AI工具生成目录
- 使用AI工具调整图表格式

**注意事项**：
- 需人工检查格式准确性
- 需符合大赛官方格式要求

## 禁止使用的场景

### 1. 核心观点生成
**禁止操作**：
- 使用AI工具生成研究假设
- 使用AI工具生成核心观点
- 使用AI工具生成创新性结论

**原因**：
- 核心观点必须由参赛者独立提出
- AI生成的内容缺乏原创性
- 违背学术诚信原则

### 2. 关键分析形成
**禁止操作**：
- 使用AI工具直接生成实证分析结果
- 使用AI工具直接生成机制检验
- 使用AI工具直接生成政策建议

**原因**：
- 分析结果必须基于真实数据和严谨方法
- AI可能生成虚假或错误的分析
- 违背科学研究的基本原则

### 3. 论文直接生成
**禁止操作**：
- 使用AI工具直接生成完整论文
- 使用AI工具直接生成大段正文
- 使用AI工具直接生成参考文献

**原因**：
- 论文必须由参赛者独立撰写
- AI生成的内容缺乏深度和逻辑
- 严重违反学术诚信

### 4. 数据伪造
**禁止操作**：
- 使用AI工具生成虚假数据
- 使用AI工具篡改真实数据
- 使用AI工具伪造统计结果

**原因**：
- 数据造假是严重的学术不端
- 一经发现将取消参赛资格
- 影响个人学术声誉

## AI工具使用情况表填写指南

### 表格基本信息
**表头信息**：
- 作品编号
- 论文题目
- 参赛队员及指导老师签字
- 学校公章

### 使用情况填写规范

#### 1. 使用的AI工具
**填写内容**：
- 工具名称（如ChatGPT、Claude、New Bing等）
- 工具版本（如有）
- 使用时间段

**示例**：
```
工具名称：ChatGPT 4.0
使用时间段：2026年3月15日 - 2026年4月20日
```

#### 2. 使用场景描述
**填写内容**：
- 具体在论文撰写的哪个环节使用
- 使用AI工具的目的
- AI工具提供的具体功能

**示例**：
```
使用场景：
1. 文献检索阶段：使用ChatGPT辅助设计检索关键词，整理文献摘要
2. 数据分析阶段：使用ChatGPT编写Python数据处理代码，调试代码错误
3. 语言润色阶段：使用ChatGPT检查论文语法错误，优化语言表达
```

#### 3. 使用方式说明
**填写内容**：
- 如何使用AI工具
- 输入了什么内容
- 获得了什么输出
- 如何处理和修改输出内容

**示例**：
```
使用方式：
- 输入："请帮我编写一个Python函数，用于处理缺失值，使用均值填充法"
- 输出：获得了一段Python代码
- 处理方式：理解代码逻辑后，根据实际数据特点进行了修改和优化，添加了详细注释
```

#### 4. 自主贡献说明
**填写内容**：
- 论文中哪些部分是独立完成的
- AI工具的使用比例
- 论文的核心创新点和原创性贡献

**示例**：
```
自主贡献：
- 研究假设的提出：100%自主完成
- 文献综述：80%自主完成，20%使用AI辅助整理
- 数据收集：100%自主完成
- 实证分析：70%自主完成，30%使用AI辅助编写代码
- 结果分析：100%自主完成
- 结论与建议：100%自主完成

核心创新点：本文提出的新指数构建方法完全由团队独立提出和验证。
```

#### 5. 声明与承诺
**填写内容**：
- 声明使用AI工具的情况属实
- 承诺遵守学术诚信
- 承担使用不当的责任

**示例**：
```
声明：
本人郑重声明，以上填写内容属实，未隐瞒任何AI工具使用情况。如发现虚假陈述，本人愿意承担相应责任，并接受大赛组委会的处理。

承诺：
本人承诺在使用AI工具过程中，严格遵守学术诚信原则，不利用AI工具进行任何形式的学术不端行为。论文的核心观点、创新性结论和关键分析均由团队独立完成。
```

### 填写注意事项

1. **真实性原则**
   - 必须如实填写所有使用情况
   - 不得隐瞒或虚假陈述
   - 如发现虚假填写将取消参赛资格

2. **详细性原则**
   - 详细描述使用场景和方式
   - 具体说明输入输出内容
   - 明确自主贡献比例

3. **准确性原则**
   - 准确记录工具名称和版本
   - 准确描述使用时间段
   - 准确说明使用目的

4. **规范性原则**
   - 按照表格要求填写
   - 使用规范的语言表达
   - 字迹清晰，签名完整

## 学术诚信要求

### 核心要求
1. **原创性原则**
   - 论文的核心观点和创新点必须由参赛者独立提出
   - 不得将AI生成的内容直接作为自己的原创观点
   - 必须对AI生成的内容进行深度加工和原创性改造

2. **透明性原则**
   - 如实报告AI工具使用情况
   - 在论文中适当说明AI工具的使用
   - 不隐瞒、不虚报使用情况

3. **责任性原则**
   - 对使用AI工具产生的所有内容负责
   - 对论文的全部内容承担学术责任
   - 不得以"AI生成"为由推卸责任

### 学术不端行为
以下行为属于学术不端：

1. **抄袭剽窃**
   - 直接复制AI生成的内容
   - 将AI生成的内容作为自己的原创成果
   - 未对AI生成内容进行适当引用和说明

2. **数据造假**
   - 使用AI生成虚假数据
   - 篡改AI生成或处理的数据
   - 伪造统计分析结果

3. **虚假声明**
   - 在AI工具使用情况表中隐瞒使用情况
   - 虚报自主贡献比例
   - 提供虚假的声明和承诺

4. **代写代答**
   - 完全依赖AI工具生成论文
   - 使用AI工具直接完成答辩准备
   - 在答辩中使用AI实时生成答案

### 违规后果
1. **取消参赛资格**
   - 一经发现学术不端行为，立即取消参赛资格
   - 已获奖的，取消获奖资格并追回证书

2. **通报批评**
   - 向所在学校通报违规情况
   - 记入学术诚信档案

3. **责任追究**
   - 承担相应的学术责任
   - 影响个人学术声誉和发展

## 常见问题

### Q1：是否可以使用AI工具翻译英文文献？
A1：可以用于翻译辅助，但建议：
- 对翻译内容需人工核对准确性
- 重要文献建议阅读英文原文
- 避免完全依赖翻译工具

### Q2：AI生成的代码可以直接使用吗？
A2：原则上可以，但必须：
- 理解代码的逻辑和原理
- 根据实际需求进行修改和优化
- 添加详细的注释说明
- 验证代码的正确性

### Q3：可以使用AI工具进行数据分析吗？
A3：可以使用AI辅助，但：
- 必须亲自理解分析方法
- 必须验证分析结果的正确性
- 不能让AI直接生成结论
- 必须解释分析的经济含义

### Q4：AI工具使用情况表不填写会有什么后果？
A4：
- 属于违规行为，将取消参赛资格
- 建议如实填写，即使使用很少也要说明

### Q5：如何证明论文的原创性？
A5：
- 详细记录研究过程和工作日志
- 保存原始数据、代码和分析过程
- 在AI工具使用情况表中明确自主贡献比例
- 在答辩时能够清楚说明核心创新点

### Q6：使用AI工具会被认为是作弊吗？
A6：
- 合理使用AI工具不被视为作弊
- 关键是如实报告、合理使用、保证原创性
- 禁止使用AI工具进行学术不端行为

### Q7：查重时AI生成的内容会被检测出来吗？
A7：
- 部分AI生成内容可能被检测到
- 建议对AI生成内容进行深度修改和原创性改造
- 避免直接复制粘贴AI生成的内容

### Q8：答辩时可以使用AI工具吗？
A8：
- 答辩过程中禁止使用任何外部辅助工具
- 答辩准备时可以使用AI辅助准备材料
- 但答辩时必须凭借自己的理解和记忆

## 最佳实践建议

### 使用AI工具的合理流程
1. **明确需求**：明确需要AI工具解决的问题
2. **合理提问**：清晰准确地描述问题和需求
3. **批判性接受**：对AI的输出进行批判性评估
4. **深度加工**：对AI输出进行深度修改和原创性改造
5. **验证结果**：验证结果的准确性和可靠性
6. **如实记录**：详细记录使用情况

### 提高论文原创性的方法
1. **深入理解研究问题**：亲自阅读文献，深入思考
2. **独立提出假设**：基于理论分析和现实观察提出假设
3. **自主设计方法**：根据研究问题自主设计研究方法
4. **亲自分析数据**：亲自运行代码，理解分析结果
5. **独立得出结论**：基于分析结果独立得出结论
6. **原创性表达**：用自己的语言表达观点和发现

### 使用AI工具的伦理准则
1. **尊重知识产权**：不利用AI工具侵犯他人知识产权
2. **遵守学术规范**：严格遵守学术诚信和学术规范
3. **承担学术责任**：对自己使用AI工具的行为负责
4. **促进学术发展**：合理使用AI工具促进学术进步
