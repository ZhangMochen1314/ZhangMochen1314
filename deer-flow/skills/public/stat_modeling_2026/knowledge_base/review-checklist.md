## 评分标准详表

| 评审维度 | 权重 | 分值范围 | 评分要点 |
|---------|------|---------|---------|
| 选题价值 | 15% | 0-15 | 选题意义、创新性、现实价值、可行性 |
| 数据质量 | 20% | 0-20 | 数据来源、样本量、处理方法、数据描述 |
| 方法科学性 | 30% | 0-30 | 方法适用性、理论基础、模型选择、稳健性检验 |
| 分析深度 | 20% | 0-20 | 分析全面性、结果解释、机制检验、对比分析 |
| 创新性 | 10% | 0-10 | 理论创新、方法创新、应用创新 |
| 规范性 | 5% | 0-5 | 格式规范、参考文献、图表质量、语言表达 |
| **总分** | **100%** | **0-100** | |

## 各维度评审要点

### 1. 选题价值（15分）

#### 评分细则
| 分值 | 评分标准 |
|------|---------|
| 13-15分 | 选题具有重要理论价值和现实意义，视角新颖，创新点突出 |
| 10-12分 | 选题具有较好理论价值和现实意义，有一定创新性 |
| 7-9分 | 选题意义一般，创新性不明显，但尚可研究 |
| 0-6分 | 选题意义不足，或选题过于陈旧，缺乏研究价值 |

#### 评审要点
- [ ] 选题是否具有重要的理论或实践意义？
- [ ] 是否关注经济社会热点难点问题？
- [ ] 研究视角是否新颖？是否有明确的创新点？
- [ ] 选题是否具有可行性（数据可得、方法适用）？

#### 常见问题
- 选题过于宽泛，难以深入研究
- 选题缺乏现实意义，理论价值不足
- 创新点不明确，与已有研究重复
- 数据来源不明确，可行性存疑

### 2. 数据质量（20分）

#### 评分细则
| 分值 | 评分标准 |
|------|---------|
| 17-20分 | 数据来源权威可靠，样本量充足，处理方法科学规范，数据描述详尽 |
| 14-16分 | 数据来源可靠，样本量适中，处理方法基本规范，数据描述较详尽 |
| 11-13分 | 数据来源尚可，样本量偏小，处理方法一般，数据描述不足 |
| 0-10分 | 数据来源不明，样本量严重不足，处理方法不规范，数据描述缺失 |

#### 评审要点
- [ ] 数据来源是否明确、权威？
- [ ] 样本量是否充足（横截面≥100，时间序列≥30，面板≥50个个体×3年）？
- [ ] 数据处理方法是否科学（缺失值、异常值处理）？
- [ ] 是否有详细的描述性统计分析？

#### 常见问题
- 数据来源不明确，缺乏权威性
- 样本量过小，无法支撑统计分析
- 数据处理不规范，未说明处理方法
- 缺乏描述性统计，对数据特征不了解

### 3. 方法科学性（30分）

#### 评分细则
| 分值 | 评分标准 |
|------|---------|
| 26-30分 | 方法选择恰当，理论基础扎实，模型设定合理，稳健性检验充分 |
| 21-25分 | 方法选择基本恰当，理论基础较好，模型设定合理，有一定稳健性检验 |
| 16-20分 | 方法选择一般，理论基础不足，模型设定有缺陷，稳健性检验不充分 |
| 0-15分 | 方法选择不当，理论基础薄弱，模型设定错误，无稳健性检验 |

#### 评审要点
- [ ] 方法选择是否适合数据类型和研究问题？
- [ ] 是否有充分的理论支撑？
- [ ] 模型设定是否合理（变量选择、函数形式）？
- [ ] 是否进行了稳健性检验（至少一种）？
- [ ] 是否验证了模型假设（正态性、同方差性、无多重共线性）？

#### 常见问题
- 方法选择不当，未验证适用条件
- 缺乏理论支撑，方法选择随意
- 模型设定存在问题（遗漏变量、函数形式错误）
- 未进行稳健性检验，结果不可靠
- 未验证模型假设，统计检验无效

### 4. 分析深度（20分）

#### 评分细则
| 分值 | 评分标准 |
|------|---------|
| 17-20分 | 分析全面深入，结果解释透彻，有机制检验和对比分析，结论可信 |
| 14-16分 | 分析较全面，结果解释较好，有一定对比分析，结论较可信 |
| 11-13分 | 分析一般，结果解释表面化，缺乏对比分析，结论可信度一般 |
| 0-10分 | 分析肤浅，结果解释不充分，无对比分析，结论可信度低 |

#### 评审要点
- [ ] 分析是否全面（描述统计、回归分析、异质性分析）？
- [ ] 结果解释是否深入（经济含义、实际意义）？
- [ ] 是否有机制检验（中介效应、调节效应）？
- [ ] 是否有对比分析（不同方法、不同样本）？
- [ ] 结论是否基于充分的分析？

#### 常见问题
- 描述性分析过多，深度分析不足
- 结果解释表面化，缺乏经济含义
- 缺乏机制检验，只停留在相关关系
- 缺乏对比分析，无法证明结论的稳健性

### 5. 创新性（10分）

#### 评分细则
| 分值 | 评分标准 |
|------|---------|
| 9-10分 | 在理论、方法或应用上有明显创新，有突破性发现 |
| 7-8分 | 在理论、方法或应用上有一定创新，有一定新发现 |
| 5-6分 | 创新性不明显，但有部分新意 |
| 0-4分 | 缺乏创新性，与已有研究重复 |

#### 评审要点
- [ ] 理论上是否有创新（新理论、新视角）？
- [ ] 方法上是否有创新（新方法、改进方法）？
- [ ] 应用上是否有创新（新领域、新数据）？
- [ ] 是否有新的发现或结论？

#### 常见问题
- 创新点不明确，与已有研究重复
- 创新点表述模糊，缺乏实质内容
- 过度夸大创新性，实际创新有限

### 6. 规范性（5分）

#### 评分细则
| 分值 | 评分标准 |
|------|---------|
| 5分 | 格式完全符合要求，参考文献规范，图表质量高，语言表达流畅 |
| 4分 | 格式基本符合要求，参考文献基本规范，图表质量较好，语言表达较流畅 |
| 3分 | 格式有少量不规范，参考文献有一定问题，图表质量一般，语言表达一般 |
| 0-2分 | 格式严重不规范，参考文献混乱，图表质量差，语言表达差 |

#### 评审要点
- [ ] 格式是否符合大赛要求（8个部分、字体、行距等）？
- [ ] 参考文献是否规范（格式、数量、权威性）？
- [ ] 图表是否规范（三线表、编号、标题、质量）？
- [ ] 语言表达是否准确、流畅、学术化？

#### 常见问题
- 格式不符合大赛要求
- 参考文献格式错误或数量不足
- 图表不规范（无编号、无标题、不清晰）
- 语言表达口语化，缺乏学术性

## 常见问题清单

### 选题类问题
1. 选题过于宽泛，难以深入研究
2. 选题缺乏现实意义，理论价值不足
3. 创新点不明确，与已有研究重复
4. 数据来源不明确，可行性存疑
5. 选题陈旧，缺乏新意

### 文献类问题
1. 文献综述过于简单，缺乏深度
2. 引用文献过于陈旧，缺乏最新研究
3. 未指出研究空白，创新点不明确
4. 文献数量不足，支撑不够
5. 文献引用不规范

### 方法类问题
1. 方法选择不当，未验证适用条件
2. 缺乏理论支撑，方法选择随意
3. 模型设定存在问题（遗漏变量、函数形式错误）
4. 未进行稳健性检验，结果不可靠
5. 未验证模型假设，统计检验无效

### 数据类问题
1. 数据来源不明确，缺乏权威性
2. 样本量过小，无法支撑分析
3. 数据处理不规范，未说明处理方法
4. 缺乏描述性统计，对数据不了解
5. 数据与选题不匹配

### 分析类问题
1. 描述性分析过多，深度分析不足
2. 结果解释表面化，缺乏经济含义
3. 缺乏机制检验，只停留在相关关系
4. 缺乏对比分析，无法证明结论稳健性
5. 结论缺乏数据支撑，主观臆断

### 规范类问题
1. 格式不符合大赛要求
2. 参考文献格式错误
3. 图表不规范（无编号、无标题、不清晰）
4. 语言表达口语化，缺乏学术性
5. 字数过多或过少

## 评分计算方法

### 评分步骤
1. 按照各维度评分细则，对每个维度进行打分
2. 将各维度得分乘以权重，得到加权得分
3. 将各维度加权得分相加，得到总分

### 评分示例
| 评审维度 | 原始得分 | 权重 | 加权得分 |
|---------|---------|------|---------|
| 选题价值 | 12 | 15% | 1.8 |
| 数据质量 | 16 | 20% | 3.2 |
| 方法科学性 | 24 | 30% | 7.2 |
| 分析深度 | 15 | 20% | 3.0 |
| 创新性 | 7 | 10% | 0.7 |
| 规范性 | 4 | 5% | 0.2 |
| **总分** | - | **100%** | **16.1** |

### 等级划分
- **优秀**：总分≥85分，且选题价值≥12分、方法科学性≥24分
- **良好**：75分≤总分<85分
- **中等**：60分≤总分<75分
- **及格**：50分≤总分<60分
- **不及格**：总分<50分

## 优化建议库

### 选题优化
1. **聚焦研究问题**：将宽泛的选题聚焦到具体的问题或领域
2. **突出创新点**：明确理论、方法或应用上的创新
3. **增强现实意义**：选择与社会经济发展密切相关的问题
4. **验证可行性**：确保数据可得、方法适用、时间可控

### 文献优化
1. **增加文献数量**：核心文献10-15篇，总文献30-45篇
2. **更新文献时效**：重点参考近3年的研究成果
3. **深化文献综述**：采用"述评结合"，指出研究空白
4. **规范文献引用**：严格按照格式要求，确保准确性

### 方法优化
1. **验证适用条件**：检验数据是否符合方法假设
2. **加强理论支撑**：说明方法选择的理论依据
3. **完善模型设定**：检查变量选择、函数形式是否合理
4. **增加稳健性检验**：至少进行一种稳健性检验

### 数据优化
1. **明确数据来源**：详细说明数据出处和获取过程
2. **扩大样本规模**：确保样本量满足统计要求
3. **规范数据处理**：说明缺失值、异常值的处理方法
4. **增加描述性统计**：全面了解数据特征

### 分析优化
1. **深化分析内容**：增加机制检验、异质性分析
2. **完善结果解释**：深入阐述经济含义和实际意义
3. **增加对比分析**：使用不同方法或样本验证结论
4. **强化逻辑链条**：确保分析过程清晰、结论可靠

### 规范优化
1. **严格格式要求**：按照大赛要求调整论文格式
2. **规范参考文献**：检查格式、数量、权威性
3. **提升图表质量**：确保清晰、规范、美观
4. **优化语言表达**：使用学术化、准确、流畅的语言
