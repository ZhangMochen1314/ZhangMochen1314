## 数据分析方法选择

### 数据类型与方法映射
| 数据类型 | 推荐方法 | 典型应用场景 |
|---------|---------|-------------|
| 横截面数据 | 回归分析、因子分析、聚类分析 | 影响因素研究、综合评价、分类分组 |
| 时间序列数据 | 时间序列分析、ARIMA模型 | 趋势预测、周期性分析 |
| 面板数据 | 面板回归模型、固定/随机效应模型 | 多个体多时点研究 |
| 文本数据 | 文本挖掘、情感分析、主题模型 | 舆情分析、内容研究 |

### 常用统计方法
1. **描述统计**：均值、方差、相关系数等基础分析
2. **回归分析**：线性回归、Logistic回归、多项式回归
3. **多元统计**：主成分分析、因子分析、聚类分析、判别分析
4. **时间序列**：平稳性检验、ARIMA、VAR模型
5. **机器学习**：决策树、随机森林、支持向量机、神经网络
6. **因果推断**：DID、PSM、工具变量法

### 方法选择决策流程
1. 明确研究问题（描述/预测/因果）
2. 识别数据类型和特征
3. 检查数据质量（完整性、准确性）
4. 选择适合的统计方法
5. 验证方法适用条件
6. 解释分析结果

详细方法参考见：[references/statistical-methods-reference.md](references/statistical-methods-reference.md)

## 数据分析与代码执行

### 核心功能：自动化数据分析
**这是本技能最核心的优势功能！**

智能体可以为您自动化完成数据分析全流程：

1. **自动编写代码**
   - 根据您的数据类型和研究问题，自动生成Python/R分析代码
   - 包含数据加载、清洗、建模、可视化等完整流程
   - 代码自动添加详细注释

2. **自动执行分析**
   - 一键运行代码，自动完成数据处理和统计建模
   - 支持描述统计、回归分析、时间序列、机器学习等多种方法
   - 自动检验模型假设，进行稳健性检验

3. **自动生成结果**
   - 自动输出统计结果（系数、标准误、t值、p值、R²等）
   - 自动生成高质量图表（散点图、折线图、箱线图、热力图等）
   - 自动保存分析结果和图表文件

4. **自动解释结果**
   - 深度解释统计结果的经济含义和实际意义
   - 分析变量间的影响机制
   - 提供政策建议和研究启示

### 使用方式
只需提供您的数据和需求，智能体即可自动完成：
```
用户：我有某省2015-2025年的面板数据，包含GDP、消费、投资等变量，
      请分析消费对GDP的影响
智能体：✓ 自动编写面板回归模型代码
         ✓ 自动执行数据清洗和分析
         ✓ 自动输出回归结果和图表
         ✓ 自动解释结果含义
```

### 代码编写指导
智能体可协助编写数据分析代码（Python/R），推荐使用以下工具库：
- **Python**：pandas、numpy、scikit-learn、statsmodels、matplotlib、seaborn
- **R**：tidyverse、caret、ggplot2、lmtest

### 数据分析流程
1. **数据加载与探索**：导入数据，查看基本结构
2. **数据清洗**：处理缺失值、异常值、重复值
3. **描述性分析**：计算统计量，绘制可视化图表
4. **模型建立**：选择并训练统计模型
5. **模型评估**：检验模型拟合度、预测能力
6. **结果解释**：分析模型参数、预测结果

**常见问题**：方法论问题、数据问题、结果解释问题、创新性问题

详细答辩准备指南见：[references/paper-writing-template.md](references/paper-writing-template.md)

## 作品审阅与优化

### 评审维度（总分100分）
| 维度 | 权重 | 评分要点 |
|------|------|---------|
| 选题价值 | 15% | 选题意义、创新性、现实价值 |
| 数据质量 | 20% | 数据来源、样本量、处理方法 |
| 方法科学性 | 30% | 方法适用性、理论基础、模型选择 |
| 分析深度 | 20% | 分析全面性、结果解释、稳健性检验 |
| 创新性 | 10% | 理论创新、方法创新、应用创新 |
| 规范性 | 5% | 格式规范、参考文献、图表质量 |

### 常见问题清单
1. **选题问题**
   - 选题过于宽泛，难以深入
   - 数据来源不明确
   - 缺乏现实意义

2. **文献问题**
   - 文献综述过于简单，缺乏深度
   - 引用文献过于陈旧
   - 未指出研究空白

3. **方法问题**
   - 方法选择不当，未验证适用条件
   - 模型说明不充分
   - 缺乏稳健性检验

4. **数据问题**
   - 样本量过小
   - 数据处理不规范
   - 数据来源不清晰

5. **分析问题**
   - 描述性分析过多，深度不足
   - 结果解释表面化
   - 缺乏对比分析

6. **规范问题**
   - 格式不符合要求
   - 参考文献格式错误
   - 图表质量不高

### 优化建议
- **针对性改进**：根据审阅意见逐条修改
- **补充分析**：增加稳健性检验、对比分析
- **完善表述**：增强逻辑性、准确性、可读性
- **规范格式**：严格按照大赛要求调整

详细评审标准见：[references/review-checklist.md](references/review-checklist.md)

## 使用示例

### 场景1：选题指导
**用户询问**：我想研究数字经济对就业的影响，这个选题合适吗？
**智能体执行**：根据选题指导原则，评估该选题的数据可得性、方法适用性、创新性，给出优化建议，如"建议聚焦于某个行业或地区，使用省级面板数据，采用固定效应模型分析"

### 场景2：文献搜集
**用户询问**：请帮我搜集关于数字金融与经济增长的相关文献
**智能体执行**：指导用户使用知网检索，设计关键词组合"数字金融 经济增长 实证研究"，优先筛选核心期刊近5年文献，收集10-15篇核心文献的题目、作者、摘要信息

### 场景3：数据分析方法选择
**用户询问**：我有5年的省级面板数据，想研究居民消费的影响因素，应该用什么方法？
**智能体执行**：根据数据类型推荐面板回归模型，指导用户进行豪斯曼检验选择固定效应或随机效应模型，提供Python代码示例

### 场景4：查重报告准备
**用户询问**：论文查重要怎么做？重复率过高怎么办？
**智能体执行**：指导用户登录知网查重系统，选择"职称评审"类型，下载"全文标明引文"报告，提供降重建议和修改策略

### 场景5：AI工具使用规范
**用户询问**：我可以使用AI工具辅助写论文吗？如何填写AI工具使用情况表？
**智能体执行**：说明允许和禁止使用AI工具的场景，指导如何如实填写AI工具使用情况表，强调学术诚信要求

### 场景6：答辩准备
**用户询问**：答辩时专家会问什么问题？如何准备？
**智能体执行**：提供常见问题清单，指导PPT制作要点，给出陈述技巧和时间分配建议

### 场景7：作品审阅
**用户询问**：请帮我审阅这篇论文，指出问题和改进建议
**智能体执行**：按照评审维度逐项打分，指出具体问题（如"文献综述部分缺少对国外研究的梳理"、"模型稳健性检验不充分"），提供详细改进建议

## 注意事项

- 文献搜集利用智能体的网络访问能力，无需脚本
- 代码执行使用智能体原生能力，支持Python/R等语言
- 论文格式需严格遵循大赛官方要求
- AI工具使用需如实报告，遵守学术诚信原则
