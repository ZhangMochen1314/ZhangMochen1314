# 文献卡片格式模板

## 概览
本文档定义文献深度解析后的结构化输出格式，确保每篇文献信息的完整性和一致性。

## 文献卡片标准格式

```markdown
## [文献标题]
- **作者**：[作者列表，格式：姓, 名; 姓, 名]
- **年份**：[发表年份]
- **期刊/来源**：[期刊名称或会议名称]
- **DOI**：[DOI链接，若有]
- **研究问题**：[研究的核心问题或目的]
- **理论框架**：[使用的理论或提出的假设]
- **研究方法**：[定性/定量/混合方法，具体方法名称]
- **数据来源**：[样本特征、数据采集方式、样本量]
- **主要发现**：[关键结论和重要发现]
- **贡献与局限**：[学术贡献与实践价值；研究的局限性]
- **关键词**：[关键词列表]
- **主题分类**：[所属主题类别]
- **备注**：[其他重要信息]
```

## 字段详细说明

### 必填字段

| 字段名 | 说明 | 示例 |
|--------|------|------|
| 标题 | 文献完整标题 | "人工智能在医疗诊断中的应用研究综述" |
| 作者 | 标准化作者格式 | "张, 三; 李, 四; Wang, John" |
| 年份 | 发表年份 | "2023" |
| 研究问题 | 核心研究问题或目的 | "探讨AI诊断系统在临床实践中的准确性和可接受度" |
| 研究方法 | 研究方法论 | "系统综述、Meta分析、案例研究、问卷调查" |
| 主要发现 | 核心结论 | "AI诊断准确率达95%，但医生接受度仅为60%" |

### 可选字段

| 字段名 | 说明 | 示例 |
|--------|------|------|
| 期刊/来源 | 发表载体 | "Nature Medicine" |
| DOI | 数字对象标识符 | "10.1038/s41591-023-01234-5" |
| 理论框架 | 理论基础 | "技术接受模型（TAM）" |
| 数据来源 | 样本信息 | "中国三甲医院，500名医生，2020-2022年数据" |
| 贡献与局限 | 学术价值与不足 | "贡献：首次验证AI诊断在中国医疗环境的应用；局限：样本局限于三甲医院" |
| 关键词 | 主题关键词 | "人工智能, 医疗诊断, 临床应用" |
| 主题分类 | 所属主题类别 | "AI医疗应用" |

## 信息提取指南

### 从摘要提取

当仅有摘要信息时，按以下优先级提取：

1. **研究问题**：通常在摘要开头，表述为"本研究旨在..."、"本研究探讨了..."
2. **研究方法**：查找"采用...方法"、"使用...进行..."等表述
3. **主要发现**：关注"结果表明..."、"研究发现..."、"结论..."等段落
4. **贡献与局限**：部分摘要会提及"本研究的意义"或"研究局限"

### 从全文提取

当有全文PDF时，可额外提取：

1. **理论框架**：查看文献综述部分或理论框架章节
2. **数据来源**：查看方法论部分的样本描述
3. **贡献与局限**：查看讨论部分的贡献陈述和局限性说明
4. **关键词**：查看文献首页或摘要下方

## 完整示例

```markdown
## 深度学习在医学影像诊断中的应用：系统综述与Meta分析
- **作者**：Wang, Li; Chen, Ming; 张, 伟; 刘, 芳
- **年份**：2023
- **期刊/来源**：Nature Medicine
- **DOI**：10.1038/s41591-023-01234-5
- **研究问题**：评估深度学习算法在医学影像诊断中的准确性，并与放射科医生诊断结果进行比较
- **理论框架**：基于深度卷积神经网络（CNN）的图像识别理论
- **研究方法**：系统综述与Meta分析，纳入2015-2022年发表的45项研究
- **数据来源**：PubMed、Web of Science、EMBASE数据库，共纳入45项研究，包含32,000+病例
- **主要发现**：深度学习诊断准确率中位数为94.5%（IQR: 89.2%-97.3%），与放射科专家诊断准确率（93.8%）无统计学差异；在特定疾病（如肺结节检测）上AI表现优于初级放射科医生
- **贡献与局限**：贡献：首次系统性评估深度学习在多病种影像诊断中的表现；局限：纳入研究存在异质性，部分研究数据质量不明确，缺乏前瞻性验证研究
- **关键词**：深度学习, 医学影像, 诊断准确性, Meta分析
- **主题分类**：AI医疗诊断
- **备注**：高引用文献，被引次数500+
```

## 使用说明

1. **智能体职责**：根据摘要或全文内容，按照本模板格式生成文献卡片
2. **格式一致性**：严格遵循Markdown格式，保持字段顺序和标识符一致
3. **信息完整性**：优先填写必填字段，可选字段根据可获得信息填写
4. **语言统一**：若原文为英文，可保留英文或翻译为中文，同一综述内保持一致
