## 概览
本文档提供文献综述的结构化模板和组织原则，帮助构建逻辑清晰、层次分明的综述框架。

## 综述类型与适用场景

### 主题式综述（默认推荐）
**适用场景**：文献围绕多个核心主题展开，需按主题归纳观点

**结构模板**：
```markdown
# [综述主题]

## 1. 引言
- 研究背景与意义
- 文献综述的目的
- 文献检索范围与筛选标准
- 综述结构概览

## 2. [主题一]
### 2.1 主要观点与代表性文献
- 核心观点陈述
- 文献证据支撑 [作者, 年份]
### 2.2 方法论差异与争论
- 不同研究方法的应用
- 方法论争议与讨论
### 2.3 小结
- 主题一的核心发现
- 研究空白与不足

## 3. [主题二]
### 3.1 主要观点与代表性文献
### 3.2 方法论差异与争论
### 3.3 小结

...

## N. 研究趋势与空白
### N.1 时间演进趋势
### N.2 现有研究的不足
### N.3 未来研究方向

## N+1. 总结
- 主要发现总结
- 理论贡献
- 实践启示
```

### 时间顺序综述
**适用场景**：展示领域发展历程，识别研究演进脉络

**结构模板**：
```markdown

- 文献范围说明

## 3. 发展阶段（年份范围）

```

## 撰写原则

### 1. 论点+证据结构
每个论点必须有文献支撑：
```markdown
研究表明，人工智能在医疗诊断中的应用显著提升了诊断效率 [Wang, 2023]。然而，不同研究对诊断准确性的提升幅度存在分歧，部分研究认为准确率提升可达20% [Li, 2022]，而另一些研究则发现提升幅度仅为5-10% [Chen, 2021]。
```

### 2. 批判性评述
避免简单罗列，应进行分析和评价：
```markdown
虽然该研究样本量较大，但研究对象的代表性存在局限。所有样本均来自一线城市三甲医院，未能反映基层医疗机构的实际情况，这限制了研究结论的外推性 [Zhang, 2022]。
```

### 3. 过渡与连接
使用过渡句连接各部分：
```markdown
上述研究主要关注技术层面的问题。然而，技术应用的接受度同样值得关注。以下将讨论影响医生使用AI诊断系统的关键因素。
```

### 4. 综合与归纳
对多篇文献的观点进行综合：
```markdown
多项研究均指出数据质量是影响AI诊断准确性的关键因素 [Wang, 2023; Li, 2022; Chen, 2021]。这些研究虽然采用的数据集不同，但结论高度一致，表明数据质量问题的普遍性和重要性。
```

## 段落结构示例

### 主题段落示例
```markdown
## 2. 人工智能在医疗诊断中的应用

### 2.1 主要应用场景

人工智能在医疗诊断领域的应用主要集中在三大场景。首先是医学影像诊断，这是目前应用最为成熟的领域。多项研究表明，深度学习算法在肺结节检测、眼底病变识别等任务中的准确率已接近甚至超过放射科专家 [Wang, 2023; Li, 2022]。其次是病理诊断辅助，AI系统能够快速筛查病理切片，标记可疑区域，显著提升病理医生的工作效率 [Chen, 2021]。第三是临床决策支持，基于患者病史和检查结果，AI系统能够提供诊断建议和治疗方案推荐 [Zhang, 2022]。

然而，不同应用场景的成熟度存在显著差异。影像诊断已有大量研究验证其有效性，而临床决策支持系统的研究相对较少，且多停留在理论探索阶段 [Liu, 2021]。此外，AI诊断系统在实际临床环境中的表现往往低于实验室环境，这一"性能落差"现象值得关注 [Huang, 2023]。

### 2.2 技术方法演进

早期的医疗AI系统主要基于专家系统和规则引擎，需要人工定义诊断规则，适用范围有限 [Wang, 2015]。随着机器学习技术的发展，支持向量机、随机森林等算法开始应用于诊断任务，准确率有所提升 [Li, 2018]。近年来，深度学习的突破性进展推动了医疗AI的快速发展。卷积神经网络（CNN）在图像识别任务中表现出色，成为影像诊断的主流方法 [Wang, 2023]。更近期的研究开始探索Transformer架构在医疗诊断中的应用，初步结果显示其在处理多模态数据方面具有优势 [Chen, 2023]。

尽管技术不断进步，但现有方法仍面临若干挑战。深度学习模型的可解释性差，难以提供诊断依据，这在医疗场景中是一个严重问题 [Liu, 2022]。此外，模型的泛化能力不足，训练数据与实际临床数据的分布差异可能导致性能显著下降 [Zhang, 2023]。
```

## 小节撰写指南

### 引言撰写要点
1. 清晰阐述研究背景和意义
2. 明确综述的目的和范围
3. 说明文献检索和筛选方法
4. 简要介绍综述结构

### 主体部分撰写要点
1. 每个主题/阶段/方法独立成节
2. 采用"观点-证据-分析"结构
3. 注意段落间的逻辑衔接
4. 适当使用表格对比差异

### 结论撰写要点
1. 总结核心发现和主要结论
2. 指出研究的理论贡献和实践价值
3. 明确研究的局限性和未来方向
4. 避免引入新的文献或观点

## 表格使用建议

### 文献对比表
适用于对比不同文献的研究设计、样本、方法、发现：

| 文献 | 研究设计 | 样本量 | 研究方法 | 主要发现 |
|------|----------|--------|----------|----------|
| Wang, 2023 | 横断面研究 | 500 | 问卷调查 | 医生接受度60% |
| Li, 2022 | 实验研究 | 200 | 对照实验 | 准确率提升20% |

### 主题归纳表
适用于归纳同一主题下的文献观点：

| 观点维度 | 支持文献 | 反对/质疑文献 | 共识程度 |
|----------|----------|---------------|----------|
| AI提升诊断效率 | [Wang, 2023; Li, 2022] | 无 | 高 |
| AI准确率超医生 | [Chen, 2021] | [Liu, 2022] | 存在争议 |

## 注意事项

1. **避免过度引用**：每个论点引用2-3篇关键文献即可，不必堆砌
2. **保持批判性**：指出研究不足，而非简单描述
3. **注意时效性**：优先引用近5年文献，经典文献可不受此限
4. **逻辑连贯**：确保各部分之间有清晰的逻辑主线
5. **篇幅平衡**：各主题/阶段的篇幅应与其重要性匹配
