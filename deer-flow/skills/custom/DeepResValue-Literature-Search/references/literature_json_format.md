# 文献JSON数据格式规范

## 概览
本文档定义智能体搜集文献后的标准化输出格式，用于生成HTML可视化报告。

## 数据结构概览

```json
{
  "query": "检索查询字符串",
  "filters": {
    "force_filter": {
      "期刊等级": ["UTD"]
    }
  },
  "data": [
    {
      "id": "唯一标识符",
      "content": { /* 文献内容对象 */ },
      "score": 0.99,
      "new_id": "论文1"
    }
  ]
}
```

## 字段详细说明

### 顶层字段

| 字段名 | 类型 | 必需 | 说明 |
|--------|------|------|------|
| query | string | 是 | 用户的研究问题或主题描述 |
| filters | object | 否 | 检索过滤条件（如期刊等级） |
| data | array | 是 | 文献数据数组 |

### filters 对象

| 字段名 | 类型 | 说明 |
|--------|------|------|
| force_filter | object | 强制过滤条件 |
| force_filter.期刊等级 | array | 期刊等级筛选，如 ["UTD", "CSSCI"] |

### data 数组元素

| 字段名 | 类型 | 必需 | 说明 |
|--------|------|------|------|
| id | string | 是 | 文献唯一标识符（可自动生成） |
| content | object | 是 | 文献内容对象 |
| score | number | 否 | 相关性得分（0-1） |
| new_id | string | 否 | 简化标识符（如"论文1"、"论文2"） |

### content 对象（文献内容）

| 字段名 | 类型 | 必需 | 说明 |
|--------|------|------|------|
| 中文标题 | string | **是** | 中文文献标题 |
| 英文标题 | string | 否 | 英文文献标题 |
| 作者 | string | **是** | 作者列表，用分号分隔（如：张三;李四;王五） |
| 期刊名 | string | **是** | 期刊名称 |
| 出版时间 | string | **是** | 出版日期（格式：YYYY-MM-DD 或 YYYY-MM-DD HH:mm:ss） |
| 期刊等级 | string | 否 | 期刊等级（UTD/CSSCI/SCI等） |
| 中文摘要 | string | **建议** | 中文摘要（用于报告展示和研究要素提取） |
| 英文摘要 | string | 否 | 英文摘要 |
| 中文关键词 | string | **建议** | 中文关键词，用分号分隔 |
| 英文关键词 | string | 否 | 英文关键词 |
| 文章链接 | string | **建议** | 文献原文链接URL |

## 验证规则

### 必需字段检查
1. `query` 字段必须存在且非空
2. `data` 数组必须存在且至少包含一个元素
3. 每个data元素的 `id` 和 `content` 必须存在
4. content中必须包含：中文标题、作者、期刊名、出版时间

### 数据类型检查
1. `score` 应为0-1之间的数值
2. `data` 必须为数组类型
3. 日期格式建议为 `YYYY-MM-DD` 或 `YYYY-MM-DD HH:mm:ss`

### 格式规范
1. 作者列表使用**分号（;）**分隔
2. 关键词使用**分号（;）**分隔
3. 链接应为有效的URL格式
4. 标题和摘要中不应包含多余的换行符
