## 知网检索技巧

### 免费检索方法
知网（CNKI）提供免费的文献检索功能，无需登录即可获取论文题目、作者、摘要等基本信息。

### 检索策略
1. **关键词组合**：采用"核心概念+研究对象+研究方法"的组合方式
   - 示例：`数字金融 经济增长 实证研究`
   - 示例：`乡村振兴 产业融合 计量模型`

2. **高级检索**
   - 使用AND、OR、NOT逻辑运算符
   - 设置时间范围（建议近5年，重点近3年）
   - 选择文献类型（期刊论文、学位论文）
   - 指定期刊级别（核心期刊、CSSCI、北大核心）

3. **检索式示例**
   ```
   (主题="数字经济" OR 主题="数字金融") AND (主题="经济增长" OR 主题="全要素生产率") AND (发表时间>=2019)
   ```

### 检索结果筛选
1. **按相关性排序**：优先选择与研究主题高度相关的文献
2. **按被引频次排序**：关注高被引文献，通常是领域重要成果
3. **按发表时间排序**：优先选择最新研究成果
4. **按期刊级别筛选**：优先核心期刊

## 文献筛选标准

### 基本筛选原则
1. **时间标准**：优先近5年（2019-2024），重点近3年（2021-2024）
2. **期刊级别**：优先核心期刊（CSSCI、北大核心、SCI/SSCI）
3. **相关性**：与研究主题高度相关，标题或摘要中包含关键词
4. **研究方法**：方法具有参考价值，可为本研究提供借鉴

### 质量评估标准
1. **理论贡献**：是否有新的理论视角或框架
2. **方法创新**：是否采用新颖的统计方法或模型
3. **数据质量**：数据来源可靠、样本量充足
4. **实证深度**：分析是否深入、稳健性检验是否充分
5. **引用次数**：高被引文献通常具有较高影响力

### 排除标准
1. 文献类型为新闻报道、评论、书评
2. 研究方法过于简单，缺乏学术价值
3. 数据来源不明或样本量过小
4. 与研究主题相关性较低

## 文献信息整理

### 信息收集清单
对每篇入选文献，记录以下信息：

```
文献编号：1
论文题目：数字经济对全要素生产率的影响机制研究
作者：张三，李四
期刊：《数量经济技术经济研究》
年份：2023
期数：第5期
页码：56-72
摘要：本文利用2011-2020年省级面板数据，采用固定效应模型...
研究方法：固定效应模型、中介效应模型
关键词：数字经济；全要素生产率；中介效应
引用次数：35
相关性：高度相关
借鉴价值：★★★★★
```

### 文献分类整理
1. **理论文献**：提供理论基础和概念框架
2. **方法文献**：提供统计方法和模型
3. **实证文献**：提供实证分析和数据参考
4. **综述文献**：提供研究现状和趋势

### 文献综述准备
1. **按主题归类**：将文献按研究主题分组
2. **按时间排序**：梳理研究发展脉络
3. **按方法分类**：归纳不同研究方法
4. **识别研究空白**：指出已有研究的不足

### 默认蒐集数量
根据研究需要动态调整，一般建议：
- 核心文献：10-15篇
- 相关文献：20-30篇
- 总文献：30-45篇

## 知网检索实战示例

### 研究主题：数字金融对居民消费的影响
**步骤1：设计关键词**
- 核心概念：数字金融、居民消费
- 研究方法：实证研究、面板数据
- 关键词组合：`数字金融 居民消费 实证研究`

**步骤2：执行检索**
- 进入知网高级检索
- 输入检索式：`(主题="数字金融") AND (主题="居民消费") AND (发表时间>=2019)`
- 期刊来源选择：CSSCI、北大核心
- 文献类型选择：期刊论文

**步骤3：筛选结果**
- 按被引频次排序，优先高被引文献
- 浏览标题和摘要，筛选高度相关文献
- 选择近3年的核心期刊论文

**步骤4：整理信息**
- 记录论文题目、作者、期刊、年份、摘要
- 标注研究方法和主要结论
- 评估借鉴价值

## 常见问题

Q1：知网检索不到足够的文献怎么办？
A1：扩大检索范围，尝试不同的关键词组合，降低期刊级别要求，延长发表时间范围。

Q2：如何判断文献的质量？
A2：关注期刊级别、作者背景、引用次数、研究方法的严谨性、数据的可靠性。

Q3：文献综述应该如何写？
A3：按照"研究背景-研究现状-研究空白-本文创新点"的逻辑展开，避免简单罗列，要进行分析和评述。

Q4：是否需要收集英文文献？
A4：建议收集少量英文文献，以体现国际视野，但以中文文献为主。

Q5：文献数量多少合适？
A5：核心文献10-15篇，总文献30-45篇，质量优于数量。
