**数据格式**: CSV
**编码**: UTF-8 with BOM

### 数据示例（前3行）

```csv
证券代码,证券简称,stkcd,year,行业代码,Size,Lev,ROA,ROE,Board,Indep,Dual,Top1,Top5,SOE,Province,City
```

### 数据特点

- **面板结构**: 每家企业每年一行数据
- **标识变量**: 证券代码, 证券简称, stkcd, year, 行业代码
- **变量命名**: 采用英文命名，首字母大写，如 `Size`, `ROA`, `Board`
- **数据类型**: 混合类型，包括字符串、浮点数、整数
- **缺失值**: 空值表示缺失

### 典型值示例

| 变量名 | 典型值 | 说明 |
|--------|--------|------|
| Size | 18-30 | 总资产自然对数 |
| Lev | 0.2-0.8 | 资产负债率 |
| ROA | -0.1-0.2 | 资产回报率 |

- **中缺失变量**: FL, CL, OL, Seperate（缺失率约10-15%）
- **核心变量**: Size, Lev, ROA, ROE, Board, Indep, Top1等缺失率<1%

**数据格式**: Stata DTA
**编码**: UTF-8

### 数据示例（前3行）


### 数据特点

- **面板结构**: 每家企业每年一行数据
- **标识变量**: 证券代码, 证券简称, year
- **变量命名**: 采用中文命名

### 典型值示例

| 变量名 | 典型值 | 说明 |
|--------|--------|------|
| 证券代码 | 000001-600999 | 6位股票代码 |

### 特殊说明

- **数据简洁**: 仅包含地理位置和行业分类信息
- **适用场景**: 用于企业地理分布研究、区域经济研究
- **可合并**: 可与微观企业控制变量通过证券代码和年份合并

## 使用建议

### 1. 数据读取

#### Python
```python
# 省级面板数据（CSV）
import pandas as pd
df_province = pd.read_csv('assets/province_panel/province_panel_processed.csv')

# 地级市面板数据（CSV）
df_city = pd.read_csv('assets/city_panel/city_panel_processed.csv', encoding='utf-8-sig')

# 县域面板数据（Excel）
df_county = pd.read_excel('assets/county_panel/县域面板数据_2000-2023.xlsx')

# 微观企业控制变量（CSV）
df_firm = pd.read_csv('assets/firm_controls/firm_control_variables.csv', encoding='utf-8-sig')

# 企业地理位置特征（Stata）
df_location = pd.read_stata('assets/firm_location/行业与所属省份城市.dta')
```

#### Stata
```stata
// 省级面板数据
import delimited "assets/province_panel/province_panel_processed.csv", clear

// 地级市面板数据
import delimited "assets/city_panel/city_panel_processed.csv", clear

// 县域面板数据
import excel "assets/county_panel/县域面板数据_2000-2023.xlsx", firstrow clear

// 微观企业控制变量
import delimited "assets/firm_controls/firm_control_variables.csv", clear

// 企业地理位置特征
use "assets/firm_location/行业与所属省份城市.dta", clear
```

### 2. 数据合并

```python
# 合并企业控制变量和地理位置特征
df_firm_full = pd.merge(
    df_firm,
    df_location[['证券代码', 'year', '所属省份', '所属城市', '行业名称']],
    on=['证券代码', 'year'],
    how='left'
)
```

### 3. 缺失值处理

```python
# 检查缺失值
print(df_province.isnull().sum())

# 删除高缺失率变量
df_firm = df_firm.drop(columns=['Invest2', 'Invest4'])

# 插值填充
df_city['pop'] = df_city.groupby('city')['pop'].transform(lambda x: x.interpolate())
```

### 4. 单位统一

```python
# 县域GDP从万元转换为亿元
df_county['地区生产总值_亿元'] = df_county['地区生产总值_万元'] / 10000
```

## 注意事项

1. **单位差异**: 注意不同数据集的单位可能不同（万元 vs 亿元）
2. **缺失值**: 不同数据集的缺失值处理方式不同
3. **时间范围**: 各数据集的时间范围不同，合并时注意对齐
4. **标识变量**: 使用正确的标识变量进行合并（证券代码、city_code等）
5. **编码问题**: CSV文件可能使用UTF-8 with BOM编码
