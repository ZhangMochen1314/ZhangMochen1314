# 省级面板数据 - 说明文档

## 1. 数据概况

- **数据名称**: 省级面板数据
- **文件名称**: `province_panel.dta`
- **数据来源**: 中国统计年鉴、各省统计年鉴
- **生成日期**: 2025-01-15
- **版本**: v1.0

## 2. 样本说明

- **覆盖范围**: 全国31个省级行政区
- **时间范围**: 1990-2024年
- **观测数量**: 约1,085条（31省 × 35年）
- **变量数量**: 约80个

## 3. 变量定义

### 3.1 标识变量

| 变量名 | 中文标签 | 类型 | 说明 |
|--------|----------|------|------|
| province_code | 省份代码 | str | 2位行政区划代码 |

## 4. 数据处理说明

### 4.1 缺失值处理
- 所有数值型变量缺失值统一用 `-999` 表示
- 字符型变量缺失值用空字符串表示

### 4.2 单位统一
- GDP、财政收入等价值指标单位统一为"亿元"
- 外贸指标单位为"亿美元"
- 人口指标单位统一为"万人"
- 比率指标单位为"%"（数值1-100）
- 人均指标单位统一为"元"

## 5. 适用研究场景

- 省际经济差异研究
- 区域发展研究
- 宏观经济政策评估
- 经济增长收敛分析
- 对外开放程度研究

## 6. 使用示例

### Stata
```stata
// 导入数据
use "province_panel.dta", clear

// 查看数据结构
describe
summarize

// 面板数据回归
xtset province_code year
xtreg gdp_pc fa_inv retail_sales, fe
```

### Python
```python
import pandas as pd

# 读取数据
df = pd.read_stata("province_panel.dta")

# 数据清洗
df = df.replace(-999, pd.NA)

# 基本统计
print(df.describe())
```
