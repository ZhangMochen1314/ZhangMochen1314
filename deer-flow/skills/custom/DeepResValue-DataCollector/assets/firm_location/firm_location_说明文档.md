# 企业地理位置特征数据说明

## 数据概况

- **数据名称**: 企业地理位置特征数据
- **数据类型**: 上市公司地理位置和行业分布数据
- **数据范围**: 沪深北三市A股上市公司
- **数据来源**: 恒生数据API
- **文件格式**: Stata DTA (.dta) 和 Word (.docx)

## 数据文件

| 文件名 | 大小 | 说明 |
|--------|------|------|
| 行业与所属省份城市.dta | 11MB | 主要数据文件（Stata格式） |
| 数据说明文档_整合后数据.docx | 55KB | 数据说明文档 |

## 主要数据内容

### 行业与所属省份城市.dta
包含上市公司的地理位置和行业分类信息，主要字段：

- **企业标识**:
  - Stkcd: 证券代码
  - ShortName: 证券简称

- **行业分类**:
  - 申万一级行业
  - 申万二级行业
  - 申万三级行业
  - 所属行业分类

- **地理位置**:
  - 所在省份
  - 所在城市
  - 所在县区
  - 地理坐标（经纬度）

- **企业特征**:
  - 注册地址
  - 办公地址
  - 成立时间
  - 上市日期

### 数据说明文档_整合后数据.docx
详细的数据说明文档，包含：
- 数据来源和收集方法
- 变量定义和说明
- 数据处理流程
- 数据质量控制
- 使用示例

## 使用方法

### Python
```python
import pandas as pd

# 读取DTA文件
df = pd.read_stata('firm_location/行业与所属省份城市.dta')

# 筛选特定省份
df_beijing = df[df['所在省份'] == '北京']

# 筛选特定行业
df_tech = df[df['申万一级行业'] == '电子']

# 统计各省份企业数量
province_counts = df['所在省份'].value_counts()
```

### Stata
```stata
* 读取DTA文件
use "firm_location/行业与所属省份城市.dta", clear

* 筛选特定省份
keep if 所在省份 == "北京"

* 筛选特定行业
keep if 申万一级行业 == "电子"

* 统计各省份企业数量
tabulate 所在省份
```

## 注意事项

1. **行政区划变更**: 省市县行政区划在历史年份可能有调整
2. **行业分类更新**: 申万行业分类定期更新，需要注意版本
3. **地址准确性**: 部分企业注册地址和办公地址可能不一致
4. **坐标精度**: 地理坐标可能存在一定误差

## 常用分析

### 按省份统计企业数量
```python
province_stats = df.groupby(['所在省份']).agg({
    'Stkcd': 'count',
    '申万一级行业': lambda x: x.nunique()
}).rename(columns={'Stkcd': '企业数量', '申万一级行业': '行业数量'})
```

### 按城市统计企业数量
```python
city_stats = df.groupby(['所在省份', '所在城市']).agg({
    'Stkcd': 'count'
}).rename(columns={'Stkcd': '企业数量'}).sort_values('企业数量', ascending=False)
```

### 行业地理分布

industry_location = df.groupby(['申万一级行业', '所在省份']).size().unstack(fill_value=0)
