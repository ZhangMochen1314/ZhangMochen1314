# 微观企业控制变量数据说明

## 数据概况

- **数据名称**: 微观企业控制变量数据
- **数据类型**: A股上市公司财务与治理数据
- **观测数量**: 66,653条记录
- **企业数量**: 5,654家
- **变量数量**: 84个
- **时间跨度**: 2000-2024年（25年）
- **文件大小**: 约70MB
- **数据来源**: 恒生数据API
- **文件格式**: CSV（UTF-8 with BOM编码）

## 数据结构

### 标识变量
- **证券代码**: 股票代码（6位数字）
- **证券简称**: 股票简称
- **stkcd**: 股票代码（数值型）
- **year**: 年份
- **行业代码**: 申万行业代码
- **Province**: 所属省份
- **City**: 所属城市
- **Industry**: 所属行业

## 主要变量分类

### 1. 企业规模与杠杆
- **Size**: 企业规模（总资产的自然对数）
- **Lev**: 资产负债率（负债/总资产）
- **EM1**: 权益乘数1
- **EM2**: 权益乘数2
- **DER**: 债务权益比
- **DLCR**: 流动负债现金比率

### 2. 盈利能力
- **ROA**: 资产回报率（净利润/总资产）
- **ROE**: 净资产收益率（净利润/股东权益）
- **GrossProfit**: 毛利率
- **NetProfit**: 净利率
- **ATO**: 资产周转率

### 3. 流动性与偿债能力
- **Liquid**: 流动比率
- **Quick**: 速动比率
- **CashRatio**: 现金比率
- **Cashflow**: 现金流量比率

### 4. 资产结构
- **REC**: 应收账款占比
- **INV**: 存货占比
- **FIXED**: 固定资产占比
- **Intangible**: 无形资产占比
- **Tangible**: 有形资产占比

### 5. 成长性
- **Growth**: 营业收入增长率
- **AssetGrowth**: 资产增长率
- **NetProfitGrowth**: 净利润增长率
- **Loss**: 亏损标识（1=亏损，0=盈利）

### 6. 资本结构
- **CTR1**: 短期负债比率
- **CTR2**: 长期负债比率
- **ITR**: 利息保障倍数
- **CAP**: 资本密集度

### 7. 投资指标
- **Invest1**: 投资支出/总资产
- **Invest2**: 投资支出/总资产（替代指标）
- **Invest3**: 资本性支出
- **Invest4**: 资本性支出（替代指标）

### 8. 治理结构
- **Board**: 董事会规模
- **Indep**: 独立董事比例
- **Dual**: 两职合一（董事长兼CEO=1，否则=0）
- **Seperate**: 两权分离度

### 9. 股权结构
- **Top1**: 第一大股东持股比例
- **Top5**: 前五大股东持股比例
- **Top10**: 前十大股东持股比例
- **Balance1**: Z指数（第一大股东/第二大股东）
- **Balance2**: 第二至第五大股东持股比例
- **Balance3**: 第二至第十大股东持股比例
- **Herfindahl3**: 前三大股东赫芬达尔指数
- **Herfindahl5**: 前五大股东赫芬达尔指数
- **Herfindahl10**: 前十大股东赫芬达尔指数
- **ChairHoldR**: 董事长持股比例
- **CEOHoldR**: CEO持股比例
- **SOE**: 国有企业标识（1=国有，0=民营）
- **Shares**: 总股数

### 10. 市场指标
- **BM**: 账面市值比
- **PB**: 市净率
- **TobinQ**: 托宾Q值
- **年个股回报率1**: 年个股回报率（计算方法1）
- **年个股回报率2**: 年个股回报率（计算方法2）
- **Dturn**: 换手率
- **CMIR**: 累计市场回报
- **RCA**: 相对累计收益
- **INST**: 机构投资者持股比例

### 11. 代理成本
- **FL**: 管理费用率
- **OL**: 其他应收款占比
- **CL**: 管理费用占比
- **Occupy**: 资金占用（其他应收款/总资产）
- **Mfee**: 管理费用
- **Mshare**: 管理层持股比例

### 12. 审计与披露
- **Big4**: 四大会计师事务所审计（1=是，0=否）
- **Opinion**: 审计意见类型
- **AuditFee**: 审计费用

### 13. 高管特征
- **Employee**: 员工数量
- **Executives**: 高管人数
- **TMTAge**: 高管团队平均年龄
- **Female**: 女性高管比例
- **TMTPay1**: 高管薪酬（计算方法1）
- **TMTPay2**: 高管薪酬（计算方法2）

### 14. 企业年龄
- **ListAge**: 上市年龄
- **FirmAge**: 企业年龄

## 缺失值说明

### 高缺失率变量（建议谨慎使用）
- **Invest4** (94.47%): 资本性支出替代指标
- **Invest2** (81.05%): 投资支出替代指标

### 中等缺失率变量
- **CL** (15.70%): 管理费用占比
- **FL** (15.70%): 管理费用率
- **Invest3** (15.22%): 资本性支出
- **OL** (14.71%): 其他应收款占比
- **Seperate** (12.67%): 两权分离度
- **TMTPay1** (8.23%): 高管薪酬
- **TMTPay2** (7.97%): 高管薪酬

### 低缺失率变量（<10%）
- 大部分财务和治理变量缺失率<10%
- 核心变量（Size, Lev, ROA, ROE等）缺失率<1%

## 使用建议

### 核心控制变量（推荐使用）
以下变量缺失率低、数据质量高，建议优先使用：
- **规模与杠杆**: Size, Lev
- **盈利能力**: ROA, ROE, GrossProfit
- **流动性**: Liquid, Quick
- **成长性**: Growth, AssetGrowth
- **治理结构**: Board, Indep, Dual
- **股权结构**: Top1, Top5, SOE
- **市场指标**: BM, TobinQ

### 审慎使用变量
以下变量缺失率较高，使用时需注意：
- **投资指标**: Invest2, Invest4（缺失率>80%）
- **代理成本**: FL, CL, OL（缺失率约15%）
- **高管薪酬**: TMTPay1, TMTPay2（缺失率约8%）
- **两权分离**: Seperate（缺失率约13%）

## 数据用途

### 主要用途
1. **实证研究**: 提供企业层面控制变量
2. **面板回归**: 企业-年份面板数据分析
3. **横截面分析**: 企业间比较
4. **时间序列分析**: 企业绩效变化趋势

### 适用研究场景
- 公司治理研究
- 企业绩效研究
- 投资决策研究
- 融资约束研究
- 代理成本研究
- 企业创新研究

## 使用示例

### 面板回归模型
```stata
* 读取数据
use "firm_control_variables.csv", clear

* 设置面板
xtset 证券代码 year

* 面板回归
xtreg Y Size Lev ROA ROE Board Indep Dual Top1 SOE i.year, fe cluster(证券代码)
```

### 横截面回归
```stata
* 单年截面回归
use "firm_control_variables.csv", clear
keep if year == 2023

reg Y Size Lev ROA ROE Board Indep Dual Top1 SOE
```

### 描述性统计
```stata
* 核心变量描述性统计
sum Size Lev ROA ROE Board Indep Dual Top1 SOE

* 按年份分组统计
by year: sum Size Lev ROA ROE
```

## 注意事项

1. **缺失值处理**: 高缺失率变量建议删除或谨慎使用
2. **异常值处理**: 建议对连续变量进行winsorize处理
3. **时间一致性**: 部分变量在不同年份计算口径可能不同
4. **行业分类**: 建议使用行业固定效应控制行业差异
5. **样本选择**: 注意退市企业、ST企业等特殊情况

## 技术说明

- **编码**: UTF-8 with BOM
- **软件兼容**: 可在Stata、Python、R中读取
