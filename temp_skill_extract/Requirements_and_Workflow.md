# 智能体科研绘图模板库系统需求文档

## 1. 项目背景与目标
为 `deerflow2.0` 智能体打造一个专业、美观、标准化的 Python 科研绘图模板库。
目标是支持涵盖**人文社科领域的数据分析**、**国家级竞赛（如正大杯）**以及**核心期刊论文**等高标准场景。系统需为每种统计图表生成两种独立风格（学术风与商业风），并配套一套自动化的打分评估工作流，通过人工筛选确立最佳的默认绘图模板。

---

## 2. 核心排版与样式规范（“最小改变原则”）

基于用户提供的参考文档（`实证论文统计图.docx`），确立了所有输出图表必须严格遵循以下基准配置：

### 2.1 尺寸与格式
- **输出格式**：统一采用高清无损的 `PNG` 格式。
- **分辨率**：高分辨率导出，至少为 `dpi=300`。
- **图片尺寸**：
  - 宽度必须严格适配 **A4 页面宽度**（约 6.3 英寸 / 16cm）。
  - 高度根据**黄金比例**或常用视觉比例设定（宽度 × 0.618 ≈ 3.89 英寸）。

### 2.2 字体与排版
- **字体族**：中英混排。优先使用英文衬线体 `Times New Roman`，中文回退到 `SimSun`（宋体），确保符合核心期刊与国标规范。
- **全局字号**：默认基础字号设为 `9pt`（即小五号字），保证缩放入 A4 纸后清晰可读且不显突兀。
- **图表标题**：**禁止在图表内部添加 Title**（图题应由作者在论文外部的 Figure Caption 中补充）。
- **坐标刻度**：刻度线默认朝内，去除冗余的网格或 3D 效果。

---

## 3. 双风格绘图系统设计

针对每一种需要生成的图表，脚本需同时支持并输出以下两种迥异的视觉风格以供对比评估：

### 3.1 黑白学术风格 (Academic Style)
- **目标场景**：期刊论文发表、严谨的实证分析报告。
- **特征**：
  - 采用纯黑或灰度层级配色（`['0.0', '0.3', '0.5', '0.7']`）。
  - 保留坐标轴边框，极简设计，避免不必要的花哨元素。
  - 符合学术出版对单色印刷及黑白对比度的要求。

### 3.2 彩色商业风格 (Commercial Style)
- **目标场景**：PPT 汇报、商业数据看板、路演展示。
- **特征**：
  - 高对比度且明亮的鲜艳色彩循环（蓝、粉、青、橙、紫等）。
  - 使用 `Helvetica` 或 `Arial` 等无衬线字体（Sans-serif）。
  - 移除部分坐标轴边框以增加空间感，更粗的线条与标记点，图例带边框与阴影。

## 4. 支持生成的图表类型清单

需覆盖超过 18 种常用于高级实证分析的图表类型：

| 类别 | 包含图表 |
| :--- | :--- |
| **分布与相关性** | 小提琴图、核密度估计图、散点图（含拟合线与95%置信区间）、气泡图、相关系数热力图 |
| **回归与时间序列** | 回归系数图、杠杆-残差图、部分回归图、时间序列图、面板趋势图、断点回归图 (RDD)、DID事件研究图 |
| **复杂网络与聚类** | 社会网络图、聚类树状图、社会流动桑基图（或堆叠柱状图变体） |
| **模型与效应分析** | 因子载荷图、误差条形图、森林图（元分析）、路径分析图、中介效应图、调节效应图、潜在类别图 |
| **特定领域图表** | 交互作用图（简单斜率）、脑影像激活图（结构脑图+fMRI热力叠加） |

## 5. 自动化测试与打分工作流

为确保选出的模板质量，系统搭建了完整的“生成 -> 隔离 -> 评分”闭环流程：

### 5.1 隔离式批量生成 (generate_all.py)
1. 自动执行所有的绘图函数。
2. 为每次绘制的图表单独创建一个具备唯一性名称的文件夹：`图片名字_时间戳`（例如 `plot_distribution_1682312345/`）。
3. 文件夹内包含：
   - `academic.png`（学术版高清图）
   - `commercial.png`（商业版高清图）
   - `source_code.py`（该图表专属的 Python 绘图源码）
   - `info.md`（图表功能与场景说明文档）

### 5.2 交互式评分应用 (score_app.py)
1. 基于 `Gradio` 构建本地 Web 交互打分界面。
2. 应用自动扫描并加载所有生成好的对比图表。
3. **对比展示**：界面左侧展示学术版图片，右侧展示商业版图片。
4. **打分机制**：提供两个范围为 `0-100` 的滑动条，用户通过滑动为两种风格分别打分。
5. **数据持久化**：点击保存后，自动切换至下一组图表，当前评分数据追加写入本地的 `scores.csv` 文件中，用于最终的数据分析与最佳模板筛选。
