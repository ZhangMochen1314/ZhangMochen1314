# 科研绘图技能 (Scientific Plotting Skill)

**Description:**
生成、自动打分与迭代高质量学术与商业 Python 绘图模板库。支持超过 18 种高级科研图表，满足顶级期刊和商业演示需求。

## 技能工作流 (Skill Workflow)

本技能建立了一个从**绘图生成**到**自动评估筛选**的完整闭环：

### 1. 自动生成阶段 (`generate_all.py`)
- **功能**: 调用底层绘图库，为每一种图表（如断点回归图、小提琴图、脑影像激活图等）生成两种不同风格的 PNG 图片。
- **输出隔离**: 将每张生成的图表隔离存入 `output_templates/` 目录中，命名为 `<图表类型>_<时间戳>`，其中包含 `academic.png`、`commercial.png` 及其源代码和说明。
- **风格规范**: 
  - **学术风格 (Academic)**: 纯黑白灰配色，A4 黄金比例，无冗余装饰，中英文字体遵循国标（如宋体/Times New Roman）。
  - **商业风格 (Commercial)**: 彩色高对比度，16:9 比例，现代无衬线字体，强调视觉层次。

### 2. 自动评分与筛选阶段 (`auto_score_pipeline.py`)
- **功能**: 模拟大语言模型（LLM）的视觉评分能力，按照用户定义的**规则 A（学术黑白简约风格）**与**规则 B（商业化彩色风格）**，对所有生成的图片进行打分。
- **评分维度**: 
  - *学术风*: 配色合规性、简洁度与去冗余、对比度与可读性、信息层次与结构、学术严谨性表达。
  - *商业风*: 色彩吸引力与和谐度、信息映射的合理性、视觉层次与引导、无障碍与通用性、商业调性的把控。
- **最佳筛选**: 根据评分 JSON 输出的总分 (`total_score`)，自动对比同类型图表的多次生成结果，筛选出最佳代码。

### 3. 模板归档阶段
- **功能**: 自动将获胜的 Python 绘图源码 (`source_code.py`) 以及其评分凭证（`_score.json`）提取并归档至 `best_templates/` 目录中。
- **结果**: 最终形成的 `best_templates/` 即为当前经过验证的最高质量的绘图代码模板库。

## Prompt 模板示例
用于视觉评分的提示词如下：

```text
你是一位精通科研视觉传达的评审专家。请先判断输入图片的视觉风格：若整体为黑白灰或单色系、设计极简，则归类为“academic_bw”；若使用多种彩色、注重视觉吸引力，则归类为“commercial_color”。然后严格按对应规则评分。

【规则A：学术黑白简约风格】
1. 配色合规性 (1-5分)
2. 简洁度与去冗余 (1-5分)
3. 对比度与可读性 (1-5分)
4. 信息层次与结构 (1-5分)
5. 学术严谨性表达 (1-5分)

【规则B：商业化彩色风格】
1. 色彩吸引力与和谐度 (1-5分)
2. 信息映射的合理性 (1-5分)
3. 视觉层次与引导 (1-5分)
4. 无障碍与通用性考虑 (1-5分)
5. 商业调性的把控 (1-5分)

请以JSON格式输出，包含：
{
  "style": "academic_bw 或 commercial_color",
  "scores": {
    "dimension_1_name": 分数,
    "dimension_2_name": 分数,
    ...
  },
  "total_score": 总分,
  "grade": "优秀/良好/中等/较差/极差",
  "summary": "一句话总结主要优劣势"
}
```
