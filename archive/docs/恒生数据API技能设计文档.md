# 恒生数据API扣子技能设计文档

## 1. 技能概述

### 1.1 技能名称
`恒生数据查询技能`

### 1.2 技能描述
本技能提供恒生数据API的便捷查询接口，支持股票、指数、财务、行情、技术指标等7大模块的数据查询，满足科研实证分析和金融交易的数据搜集需求。用户通过自然语言指令即可获取结构化数据，支持多种输出格式。

### 1.3 核心价值
- **一站式数据查询**：覆盖A股市场全维度数据
- **自然语言交互**：无需记忆复杂API参数和URL
- **多格式输出**：支持Markdown、Excel、JSON等格式
- **专业可靠**：基于官方恒生数据API，数据准确及时

## 2. 技能架构

### 2.1 支持的数据模块
基于API文档，技能支持以下7大模块：

| 模块编号 | 模块名称 | 主要功能 | 典型查询场景 |
|----------|----------|----------|--------------|
| 1 | 股票列表 | 基础股票信息、新股日历、概念指数等 | 获取全市场股票列表、查看近期新股 |
| 2 | 指数/行业/概念 | 分类树、股票与分类关联查询 | 查找特定行业的所有股票、查询股票所属概念 |
| 3 | 涨跌股池 | 涨停、跌停、强势、次新、炸板股池 | 获取当日涨停股票、分析强势股特征 |
| 4 | 上市公司详情 | 公司简介、财务指标、股东信息、分红增发等 | 查询公司基本面、分析财务健康度 |
| 5 | 实时交易 | 实时价格、买卖盘口、资金流向等 | 监控个股实时行情、分析资金动向 |
| 6 | 行情数据 | 历史分时交易、涨跌停价格、行情指标 | 获取历史K线数据、分析价格走势 |
| 7 | 技术指标 | MACD、MA、BOLL、KDJ等指标 | 技术分析、买卖信号判断 |

### 2.2 技能参数结构

#### 2.2.1 核心参数

| 参数名称 | 类型 | 必填 | 默认值 | 说明 |
|----------|------|------|--------|------|
| `module` | 枚举 | 是 | - | 查询模块：`stock_list`、`category`、`pool`、`company`、`realtime`、`market`、`technical` |
| `action` | 枚举 | 是 | - | 具体操作，如`get_list`、`get_details`等 |
| `symbol` | 字符串 | 否 | - | 股票代码（如000001） |
| `date` | 字符串 | 否 | 当日 | 日期，格式yyyy-MM-dd |
| `category_code` | 字符串 | 否 | - | 分类代码（从分类树获取） |
| `timeframe` | 枚举 | 否 | d | 时间周期：5/15/30/60/d/w/m/y |
| `adjust` | 枚举 | 否 | n | 除权方式：n/f/b/fr/br |
| `limit` | 整数 | 否 | 100 | 返回数据条数 |
| `start_date` | 字符串 | 否 | - | 开始日期 |
| `end_date` | 字符串 | 否 | - | 结束日期 |
| `output_format` | 枚举 | 否 | md | 输出格式：`md`、`excel`、`json` |

#### 2.2.2 许可证管理
- **默认许可证**：技能初始化时配置默认许可证 `C841AA1C-5254-4A61-8D67-784345430241`
- **自定义许可证**：支持用户通过指令临时指定其他许可证

## 3. 用户交互设计

### 3.1 触发指令
用户可通过以下方式触发技能：

**基础指令**：
- `查询[股票代码]实时数据` → 获取个股实时交易
- `获取[日期]涨停股池` → 查询指定日期涨停股票
- `查看[股票代码]财务指标` → 获取公司财务数据
- `导出[股票代码]历史行情` → 导出历史数据到Excel

**高级指令**：
- `比较[股票代码1]和[股票代码2]的技术指标`
- `分析[行业名称]的资金流向`
- `监控[股票代码]的MACD信号`

### 3.2 参数输入方式
1. **自然语言解析**：技能自动从用户指令中提取关键参数
2. **交互式确认**：当参数不明确时，技能通过问答方式补全
3. **参数预设**：支持常用参数的预设配置

### 3.3 错误处理逻辑

| 错误类型 | 检测方式 | 用户提示 | 后续处理 |
|----------|----------|----------|----------|
| 许可证无效 | API返回错误代码 | "许可证无效，请检查许可证配置" | 提示用户重新配置许可证 |
| 股票代码错误 | API返回空数据 | "未找到股票代码[代码]，请确认代码格式" | 建议正确格式，提供示例 |
| 日期格式错误 | 参数验证失败 | "日期格式应为yyyy-MM-dd，如2025-01-15" | 自动尝试修正格式 |
| API限流 | 请求频率超限 | "请求过于频繁，请稍后再试" | 自动延迟重试或提示等待 |
| 网络异常 | 请求超时 | "网络连接异常，请检查网络后重试" | 记录日志，建议重试 |
| 数据不存在 | API返回空数组 | "指定日期的数据暂未更新" | 提示最新可用日期 |

## 4. 输出格式设计

### 4.1 Markdown格式（默认）
- **结构化展示**：使用表格、列表清晰呈现数据
- **关键指标突出**：重要数据加粗或高亮显示
- **分模块组织**：复杂数据按逻辑分组展示

**示例输出**：
```markdown
## 平安银行(000001) 实时交易数据
**更新时间**: 2025-04-01 14:30:00

| 指标 | 数值 | 单位 |
|------|------|------|
| 当前价格 | 12.45 | 元 |
| 涨跌幅 | +2.34 | % |
| 成交额 | 1.23 | 亿元 |
| 换手率 | 0.56 | % |
| 市盈率(动态) | 8.92 | 倍 |
```

### 4.2 Excel格式
- **多Sheet组织**：不同模块数据放在不同Sheet
- **完整字段**：导出所有API返回字段
- **格式优化**：数字格式、日期格式自动处理

**文件结构**：
```
股票实时数据.xlsx
├── 实时行情 (当前数据)
├── 历史行情 (时间序列)
├── 财务指标 (季度数据)
└── 资金流向 (逐笔数据)
```

### 4.3 JSON格式
- **原始API响应**：保留完整API返回结构
- **元数据包含**：添加查询参数、时间戳等元信息
- **程序友好**：便于其他系统集成调用

**JSON结构**：
```json
{
  "metadata": {
    "query": "平安银行实时数据",
    "timestamp": "2025-04-01T14:30:00Z",
    "module": "realtime"
  },
  "data": [...],
  "status": "success"
}
```

## 6. 技能实现要点

### 6.1 核心功能实现
1. **指令解析器**：自然语言转结构化参数
2. **API路由层**：参数映射到具体API端点
3. **数据格式化器**：原始JSON转多种输出格式
4. **错误处理器**：统一异常处理和用户提示

### 6.2 性能优化
- **缓存机制**：频繁查询数据本地缓存
- **批量查询**：支持多股票同时查询优化性能
- **异步处理**：大数据量导出使用异步任务

### 6.3 安全性考虑
- **许可证隔离**：不同用户使用独立许可证配额
- **请求限流**：防止恶意高频请求
- **数据脱敏**：敏感信息本地处理，不上传云端

## 7. 后续扩展方向

### 7.1 短期扩展（V1.1）
- 添加预警功能：价格突破、指标金叉等实时提醒
- 支持组合查询：多股票对比分析
- 增加可视化图表：集成ECharts生成趋势图

### 7.2 中期扩展（V2.0）
- 机器学习分析：基于历史数据的预测模型
- 自动化报告：定期生成投资分析报告
- 多市场支持：港股、美股、期货等市场数据

### 7.3 长期愿景
- 智能投顾：基于用户风险偏好的投资建议
- 研报整合：整合券商研报与基本面数据
- 量化策略：可视化量化策略回测平台
