# 验收清单 (Checklist)

## 1. 核心安全漏洞修复 (Security Hotfixes)
- [x] **密钥脱敏**：检查代码库（特别是 `.env` 和测试脚本如 `test_deepseek*.py`）中不存在任何明文的 API Key（如 `sk-xxx`）。
- [x] **强校验配置**：未配置 `JWT_SECRET_KEY` 或使用了默认值 `super-secret-key-for-dev` 时，启动服务会立即抛出异常并拒绝运行。
- [x] **强校验配置**：未配置 `DATABASE_URL` 时，启动服务不再使用默认的 SQLite 而是直接抛出异常并拒绝运行。
- [x] **文件上传拦截**：尝试通过网关接口上传超过 100MB 大小的文件时，能够被正确拦截并返回错误状态码。
- [x] **文件上传拦截**：尝试上传非白名单扩展名（如 `.exe`, `.sh`, `.tar.gz` 等）时，能够被正确拦截并返回错误状态码。
- [x] **沙箱配置**：检查 `config.yaml` 中 `allow_host_bash` 强制被设置为 `false`，彻底禁用在宿主机执行系统命令。

## 2. 存储抽象与火山引擎 TOS 集成
- [x] **接口抽象**：`StorageProvider` 接口被成功定义，`OSSProvider` 已重构以兼容该接口规范。
- [x] **配置化生效**：预签名 URL 的过期时间能够成功从系统配置文件中动态读取。
- [x] **火山引擎对接**：通过配置 `storage.provider: tos`，能够成功将测试文件直传至火山引擎 TOS 对象存储，并生成正确的预签名访问 URL。

## 3. 沙箱抽象与火山引擎 veFaaS 集成
- [x] **接口抽象**：`SandboxBackend` 接口被成功定义，现有的本地和远程沙箱已重构以兼容该接口规范。
- [x] **超时控制生效**：请求获取沙箱实例的操作具有明确的 30 秒超时限制机制，当后端无响应时能够主动中断。
- [x] **火山引擎对接**：配置 `VolcengineSandboxBackend` 后，能够通过火山引擎云沙箱的 API 动态创建、在隔离环境中执行 Python 数据分析代码，并成功获取返回的标准输出或错误信息。

## 4. 会话持久化与增强分析功能 (Session Persistence)
- [x] **会话持久化**：用户能够成功创建会话状态，且能在服务重启或在 24 小时超时内跨会话恢复先前的分析进度。
- [x] **三层存储联动**：`SessionManager` 能够正确地在 Redis、PostgreSQL 和 TOS 之间流转和存储会话元数据及快照。
- [x] **格式解析支持**：系统的数据处理模块能够成功读取和解析 SAS 格式 (`.sas7bdat`) 的数据文件。
