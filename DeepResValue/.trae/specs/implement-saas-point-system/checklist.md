# 验收清单 (Checklist)

## 1. 认证与隔离机制
- [x] 系统能够成功注册新用户，返回合法的 JWT Token。
- [x] 携带无效或过期 Token 访问受保护的核心 API（如获取历史记录）时会被拦截并返回 401。
- [x] 用户 A 无法通过 API 遍历或修改用户 B 的对话记录、配置文件和沙盒内容。

## 2. 数据库与存储架构
- [x] 系统不再将偏好记忆、对话记录全局持久化在 `USER.md` 和 `memory.json` 等单点文件中。
- [x] 所有用户的上传文件与沙盒工作区在宿主机上有明确隔离的物理路径（如 `/mnt/tenant_{user_id}/...`）。

## 3. 积分与计费流程
- [x] 用户调用大模型（如 DeepSeek-V4-Pro）后，系统能根据响应中的 `usage` (Token 使用量) 准确扣减该用户的账户积分余额。
- [x] 能够通过 API 获取详细且金额准确的积分消费流水。
- [x] 当用户积分余额为 0 或低于最低调用阈值时，大模型对话请求被准确拦截并返回 402 Payment Required 错误提示。
