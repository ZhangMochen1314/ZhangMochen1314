中国目前已彻底消除了绝对贫困，减贫事业将进入治理相对贫困的新阶段，但学界尚缺乏相应的统计指数来测度相对贫困的治理成效。为此，本文基于多维贫困理论和持续贫困理论，构建了持续多维相对贫困脱/返贫指数。利用2016-2020年中国家庭追踪调查数据（CFPS），采用A-F双重识别法和Markov链模型，测度了中国农村家庭的持续多维相对贫困状况，并分析了其时空演变特征和影响因素。研究发现：2016-2020年，中国农村持续多维相对贫困发生率显著下降，但仍存在返贫风险；地区间相对贫困治理成效差异明显，东部地区治理成效优于中部和西部地区；教育水平、社会保障、健康状况是影响相对贫困治理成效的主要因素。基于此，本文提出加大教育投入、完善社会保障体系、加强医疗卫生服务等政策建议。

关键词：相对贫困；持续多维贫困；贫困指数；A-F双重识别法；Markov链

### 正文格式示例
```
第一章  绪论

1.1 研究背景与意义

2020年，中国如期完成了新时代脱贫攻坚目标任务，彻底消除了绝对贫困。然而，相对贫困问题依然存在，并将长期伴随中国经济社会发展。相对贫困是指个人或家庭的收入或消费水平低于社会平均水平的一种状态，具有长期性、相对性和动态性特征（汪三贵等，2020）。如何科学测度相对贫困的治理成效，成为后扶贫时代亟待解决的重要问题。

长期以来，世界各国都在为消除极端贫困而努力。据世界银行估计，全球极端贫困发生率从1990年的36.2%下降到2017年的9.3%。然而，相对贫困问题并未随之消失，反而在许多国家和地区呈现加剧趋势。因此，研究相对贫困的测度方法，对于制定有效的减贫政策具有重要意义。

1.2 文献综述

1.2.1 相对贫困内涵与测度研究

相对贫困的概念最早可追溯到20世纪50年代。Townsend（1979）认为，贫困是由于缺乏社会普遍接受的资源而被排斥在社会主流生活方式之外的状态。此后，学者们从不同角度对相对贫困进行界定，形成了收入贫困、能力贫困、多维贫困等多种观点。

相对贫困的测度方法主要包括收入法和多维法。收入法以收入中位数的某个比例作为贫困线，如欧盟将收入中位数的60%作为相对贫困线。然而，收入法仅考虑收入单一维度，难以全面反映贫困状况。为此，Alkire和Foster（2011）提出了A-F双重识别法，可以从多个维度识别贫困，为多维贫困研究提供了方法论基础。

1.2.2 持续贫困研究进展

持续贫困是指个体或家庭在多个时期持续处于贫困状态。相较于单期贫困，持续贫困对个人的福利影响更为深远，是减贫政策需要重点关注的问题。

Markov链模型是研究持续贫困的常用方法。该方法通过计算个体在不同贫困状态之间的转移概率，可以识别持续贫困、脱贫、返贫等动态过程（Jalan和Ravallion，2000）。然而，现有研究多将Markov链模型应用于绝对贫困研究，在相对贫困领域的应用还较为少见。

1.2.3 研究述评

综上所述，已有研究在相对贫困和持续贫困的测度方面取得了丰富成果，但仍存在以下不足：一是缺乏专门针对相对贫困的持续多维贫困测度指数；二是缺乏考虑多维贫困动态演变的分析方法；三是对中国农村相对贫困治理成效的实证研究不足。为此，本文构建了持续多维相对贫困脱/返贫指数，并利用中国家庭追踪调查数据进行实证分析，以期为相对贫困治理提供理论依据和政策参考。

1.3 研究内容与技术路线

本文的研究内容包括：（1）构建持续多维相对贫困脱/返贫指数；（2）测度中国农村持续多维相对贫困状况；（3）分析持续多维相对贫困的时空演变特征；（4）探究持续多维相对贫困的影响因素。

## 格式规范总结

### 字体要求
- **正文**：宋体小四（12pt）
- **一级标题**：黑体三号（16pt）
- **二级标题**：黑体四号（14pt）
- **三级标题**：黑体小四（12pt）
- **图表标题**：宋体五号（10.5pt）
- **参考文献**：宋体五号（10.5pt）
- **英文、数字**：Times New Roman

### 行距要求
- **正文**：1.5倍行距
- **标题**：单倍行距
- **参考文献**：单倍行距

### 页边距
- **上下**：2.54cm
- **左右**：3.17cm

### 页码设置
- **封面、摘要、目录**：罗马数字（i, ii, iii...）
- **正文**：阿拉伯数字（1, 2, 3...）
- **页码位置**：页面底部居中

### 段落设置
- **首行缩进**：2字符
- **段前段后**：0行
- **对齐方式**：两端对齐

### 图表规范
- **表格编号**：表1、表2、表3...
- **图片编号**：图1、图2、图3...
- **编号与名称**：之间空两格
- **表格格式**：三线表（顶线、底线、栏目线）
- **标题位置**：表格在上方居中，图片在下方居中

## 注意事项

1. **文件命名**：
   - Word完整版：`作品全文—组别—作品编号`
   - PDF匿名版：`匿名作品—组别—作品编号`

2. **匿名处理**：
   - PDF版本需删除封面页和致谢
   - 正文中不得出现学校名称、队员姓名、指导老师信息

3. **文件大小**：
   - Word版和PDF版均需小于100MB

4. **页码设置**：
   - 封面页不显示页码
   - 摘要和目录使用罗马数字页码
   - 正文开始使用阿拉伯数字页码
