# Build Commercial Web App MVP Spec

## Why
大学生在进行科研、论文写作及国家级竞赛（如全国大学生统计建模大赛、正大杯等）时面临数据分析门槛高、难以复现等痛点。此外，**数据搜集与文献检索**是科研中仅次于数据分析的第二大难题。目前系统后端的 DeerFlow 2.0 结合 StatsPAI 已经具备可复现自动化数据分析的专业能力。本项目阶段的目标是将这些能力封装为商业化网页应用，并引入基于“积分”的商业化计费模式，解决大学生的痛点并实现项目商业落地与部署。

## What Changes
- **新增内置科研数据中心 (Data Hub)**：将您本地的常用科研数据（如上市微观企业指标、宏观指标：省级/市级/县域级数据）集成到系统中。用户无需手动下载上传，直接通过自然语言指令，智能体即可检索并输出所需数据。
- **集成文献自动检索与综述能力**：利用 DeerFlow 2.0 现有的 `systematic-literature-review` 技能（目前支持 arXiv 等），提供真实可靠的文献检索与自动文献综述生成功能。
- **精细化动态积分计费模型**：设计一套动态积分扣减规则，计费维度包含：
  - **数据集使用费**：根据调用的内置数据层面（微观企业 > 县域级 > 市级 > 省级 > 宏观）和输出的数据内存大小（MB）动态扣除积分，数据越微观、越庞大，收费越高。
  - **文献检索与综述费**：按检索深度和生成的综述字数扣费。
  - **数据分析费**：分析复杂度、Python执行时长、生成图片数量。
- **高品质学术 UI 与渲染 (Frontend Design)**：
  - 采用极简、严谨的学术风格 UI（象牙白/科研蓝），摒弃廉价的 AI 生成感。
  - **强大的渲染能力**：前端需原生支持渲染数据图片、数学公式（LaTeX/KaTeX）。
  - **三线表渲染**：前端 Markdown 表格必须通过自定义 CSS 渲染为标准的学术“三线表”（顶部粗线、表头下细线、底部粗线），以满足学术报告的直接复制需求。
- **重构产品首页**：针对大学生群体优化文案与 UI，突出“内置丰富科研数据”、“文献自动综述”、“可复现分析”等核心竞争力。

## Impact
- Affected specs: 商业化落地、积分消费模式、文献检索能力、内置数据中心。
- Affected code:
  - 核心页面：`src/pages/Home.tsx`, `src/pages/Chat.tsx`, `src/pages/Datasets.tsx`
  - 样式与渲染：`src/index.css` (三线表样式), Markdown 渲染组件配置
  - 业务逻辑：内置数据检索逻辑、文献检索技能对接、精细化积分计算逻辑。

## ADDED Requirements
### Requirement: 内置科研数据中心与智能提供
The system SHALL provide 内置的科研数据集库，并允许智能体根据用户指令直接提取并提供数据。

#### Scenario: 用户请求特定层面的数据
- **WHEN** 用户在对话框中输入“我需要2010-2020年中国所有上市公司的微观财务指标数据”
- **THEN** 智能体从内置数据库中匹配数据，提示预计消耗的高额积分（因微观数据量大且珍贵），用户确认后，直接在工作区输出该数据集供后续分析或下载。

### Requirement: 文献自动检索与综述
The system SHALL provide 基于真实文献库的检索与综述生成能力。

#### Scenario: 用户请求文献综述
- **WHEN** 用户输入“帮我检索关于数字经济对县域经济增长影响的最新文献，并写一篇文献综述”
- **THEN** 智能体调用系统性文献综述技能，真实检索相关文献，并输出带有标准引用格式（APA/BibTeX）的综述报告，同时根据检索广度扣除积分。

### Requirement: 精细化积分消费机制
The system SHALL provide 基于数据层面、输出大小、计算复杂度等多维度的动态积分计费机制。

#### Scenario: 提取内置数据并分析扣费
- **WHEN** 用户提取了 50MB 的市级宏观面板数据，并进行面板回归分析
- **THEN** 系统根据规则（数据调用分[市级费率 * 50MB] + 复杂度分[面板回归] + 执行耗时分）计算总消耗积分。

### Requirement: 学术级富文本与三线表渲染
The system SHALL provide 类似学术论文标准的结果展示。

#### Scenario: 渲染回归结果
- **WHEN** StatsPAI 返回包含 LaTeX 公式和回归系数表格的 Markdown 结果
- **THEN** 前端将其渲染为标准的数学公式和无垂直边框的学术三线表。
