# Advanced Plot Templates Spec

## Why
为了丰富 `deerflow2.0` 智能体的绘图能力，需要为大量高级科研和实证分析图表（如小提琴图、时间序列图、社会网络图等）建立高质量的模板。同时，为了满足不同的使用场景（学术论文与商业报告），每种图表都需要提供两种截然不同的风格：黑白配色的简约学术版，以及彩色华丽的商业报告版。用户将基于这些模板的输出进行打分，最终筛选建立专属的绘图模板库。

## What Changes
- 针对用户列出的 18 种以上的高级图表类型，分别为每种图表编写独立的 Python 绘图脚本。
- 每种图表的脚本中需同时包含生成**黑白学术风格**和**彩色商业风格**图表的逻辑。
- 确保每种风格不仅在配色上不同，在线条粗细、背景、标记样式等方面也进行相应的风格化处理。
- 所有脚本都需生成并保存对应的图片文件（如 PDF 或 PNG 格式），供用户打分评估。

## Impact
- Affected specs: 增加了大量高级统计与分析图表的独立生成模板。
- Affected code: 将在工作区创建一系列以图表类型命名的独立 `.py` 脚本文件。

## ADDED Requirements
### Requirement: 多类型高级图表支持
系统必须支持各种复杂的实证论文和商业分析图表绘制。

#### Scenario: 绘制高级图表
- **WHEN** 用户需要特定的高级图表（如断点回归图或中介效应图）
- **THEN** 系统能提供对应的 Python 脚本，使用模拟数据生成结构完整、逻辑正确的图表。

### Requirement: 双重风格输出
系统必须为每种图表提供两种预设风格。

#### Scenario: 风格对比
- **WHEN** 运行图表的生成脚本时
- **THEN** 脚本应同时输出两张图片：一张为黑白/灰度学术风，另一张为彩色华丽商业风。
